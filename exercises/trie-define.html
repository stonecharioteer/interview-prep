Trie: Define TrieNode

Tries Intermediate
Prerequisites
  • #45 Tree: Define Node — understanding tree node structure

What You Will Learn

How to define a TrieNode and build a Trie (prefix tree). You will see how inserting words like "cat", "car", and "card" creates prefix sharing — common prefixes are stored once, branching only where words diverge. Insertion is O(m) where m is the word length.

The Structure

Definition

A TrieNode has:

1. children: a map from character to child TrieNode.

2. is_end: a boolean marking whether this node completes a word.

The root node represents the empty prefix. Each edge represents a character. A path from root to an is_end=true node spells out a stored word.

Why Tries?

Key Insight

Unlike a hash set of strings, a Trie shares storage for common prefixes. This makes prefix queries ("find all words starting with 'ca'") efficient. Autocomplete, spell checkers, and IP routing all use Tries.

Time & Space Complexity

Insert: O(m) — traverse/create m nodes for a word of length m.

Search: O(m) — follow m edges from root.

Space: Worst case O(total characters), but shared prefixes save space.

Pseudocode

class TrieNode:
    def __init__(self):
        self.children = {}    # char -> TrieNode
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True       # mark end of word

Walkthrough

Inserting "cat", "car", "card"

Insert "cat":
  root -c-> (c) -a-> (a) -t-> (t, is_end=true)

Insert "car":
  root -c-> (c) -a-> (a) already exists (shared prefix!)
  (a) -r-> (r, is_end=true)

Insert "card":
  root -c-> (c) -a-> (a) -r-> (r) already exists
  (r) -d-> (d, is_end=true)

Result: "ca" prefix is shared by all three words.
"car" prefix is shared by "car" and "card".

Common Pitfalls

1. Forgetting is_end

Without is_end, you cannot distinguish "car" (a stored word) from "car" (just a prefix of "card"). Always mark word endings.

2. Using arrays vs maps for children

For lowercase English letters, a fixed array of size 26 is faster. For Unicode or sparse alphabets, use a hash map.

What You Learned

Key Takeaways

TrieNode structure: children map + is_end boolean. Simple but powerful.

Prefix sharing: Common prefixes are stored once, making Tries space-efficient for dictionaries with shared prefixes.
