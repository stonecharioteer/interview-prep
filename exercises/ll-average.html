New Concept: Combining Two Computations in a Single Pass

Average = sum / length. You could call sum() and length() separately, but that traverses the list twice. Instead, track both a running sum and a count in a single traversal.

This is an important optimization principle: when you need multiple aggregate values, compute them together in one pass rather than making separate passes.

Time & Space Complexity

Time: O(n) — single pass through all nodes.

Space: O(1) — two variables: sum and count.

Pseudocode

function average(head):
    if head is null:
        error "empty list"
    sum = 0
    count = 0
    curr = head
    while curr is not null:
        sum = sum + curr.value
        count = count + 1
        curr = curr.next
    return sum / count

What You Learned

Key Takeaways

Single-pass optimization: Track multiple aggregates simultaneously to avoid redundant traversals.

Always check for empty lists before dividing (division by zero).

This "multi-aggregate single pass" pattern appears in statistics, stream processing, and database query optimization.
