What is a Binary Tree?

Definition

A binary tree is a hierarchical data structure where each node contains a value and has at most two children: a left child and a right child.

The topmost node is the root. Nodes with no children are called leaves. The structure is inherently recursive: each child is itself the root of a smaller binary tree (or null/empty).

Key Terminology

Root: The topmost node. The entry point to the tree.

Parent: A node that has children. The node directly above.

Child: A node directly below another node (left or right).

Leaf: A node with no children (both left and right are null).

Depth: Distance from the root to a node (root has depth 0).

Height: Distance from a node to its deepest descendant leaf. The tree's height is the root's height.

Subtree: Any node and all its descendants form a subtree.

Real-World Use Cases

File systems: Directories contain files and subdirectories — a tree structure.

HTML DOM: Web pages are trees of nested elements.

Org charts: Company hierarchy with managers and reports.

Expression trees: Mathematical expressions like (3 + 4) * 5 are naturally trees.

Decision trees: Machine learning models that branch on conditions.

Binary Search Trees: Efficient lookup, insert, delete in O(log n).

The Node Structure

A Node Has Three Parts

Node:
    value     -- the data stored in this node
    left      -- reference to the left child (or null)
    right     -- reference to the right child (or null)

That is it. A tree is just a collection of nodes linked by these left/right references. The tree itself is identified by its root node.

Properties of Binary Trees

Max nodes at depth d: 2^d (level 0 has 1, level 1 has 2, level 2 has 4, ...)

Max total nodes with height h: 2^(h+1) - 1

Min height for n nodes: floor(log2(n))

A tree is balanced if left and right subtree heights differ by at most 1 at every node. Balanced trees guarantee O(log n) operations.

Pseudocode

structure Node:
    value
    left = null
    right = null

function create_node(value):
    node = new Node
    node.value = value
    return node

function insert_level_order(root, value):
    new_node = create_node(value)
    if root is null:
        return new_node
    queue = [root]
    while queue is not empty:
        current = queue.remove_front()
        if current.left is null:
            current.left = new_node
            return root
        else:
            queue.add(current.left)
        if current.right is null:
            current.right = new_node
            return root
        else:
            queue.add(current.right)
    return root

Walkthrough

         (10)

           (10)

      (3)  (7)

Common Pitfalls

1. Confusing "binary tree" with "binary search tree"

A binary tree has no ordering constraint. A binary search tree (BST) requires that left descendants are smaller and right descendants are larger. Exercise #45 is about plain binary trees.

2. Forgetting null checks

Before accessing node.left or node.right, always check that node is not null. This is the most common source of tree-related errors.

What You Learned

Key Takeaways

A binary tree node has three parts: value, left child, right child.

Root, leaf, depth, height — the vocabulary for describing tree structures.

Trees are recursive: every subtree is itself a tree.
