Container With Most Water

Two Pointers Intermediate
Required Learning
  • #62 Two Pointers: two_sum_sorted — the two-pointer pattern

The Problem

Definition

Given an array of heights where each element represents a vertical line on the x-axis, find two lines that together with the x-axis form a container that holds the most water.

The water held = min(height[left], height[right]) × (right - left)

Real-World Analogy: Two Walls and a Pool

Imagine you have a row of walls of different heights. You want to pick two walls to form the sides of a pool. Water can only fill up to the height of the shorter wall. The further apart the walls, the wider the pool — but you also want tall walls. The challenge is finding the best tradeoff between width and height.

Why Two Pointers Work

The Key Insight

Start with the widest possible container (pointers at both ends). The area is limited by the shorter wall. Moving the taller wall inward can only make things worse (narrower, and the height is still limited by the short wall). So we always move the shorter wall inward, hoping to find a taller replacement.

This greedy choice means we never miss the optimal pair. We consider O(n) pairs instead of O(n²) — because every time we move a pointer, we provably eliminate a set of suboptimal pairs.

Complexity

Time: O(n) — each pointer moves at most n times.

Space: O(1) — just two pointers and a max variable.

The Algorithm

def max_area(heights):
    left, right = 0, len(heights) - 1
    best = 0

    while left < right:
        width = right - left
        h = min(heights[left], heights[right])
        best = max(best, width * h)

        if heights[left] < heights[right]:
            left += 1       # move the shorter wall
        else:
            right -= 1

    return best

Walkthrough

Heights: [1, 8, 6, 2, 5, 4, 8, 3, 7]

Step 1: left=0 (h=1), right=8 (h=7)

Area = min(1,7) × 8 = 8. Move left (shorter).

Step 2: left=1 (h=8), right=8 (h=7)

Area = min(8,7) × 7 = 49. Best so far! Move right (shorter).

Step 3: left=1 (h=8), right=7 (h=3)

Area = min(8,3) × 6 = 18. Move right. Continue until pointers meet...

Answer: 49 (between indices 1 and 8).

Common Pitfalls

1. Moving the wrong pointer

Always move the pointer at the shorter wall. Moving the taller one can never increase the area (the height is limited by the short side, and width decreases).

2. Confusing with trapping rain water

This problem picks two walls. Trapping rain water sums water between all walls. Different problem, different approach.
