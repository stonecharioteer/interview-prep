What's New Here

Finding the middle of a linked list seems simple: count the length, then traverse to length/2. But that requires two passes. The slow/fast pointer (tortoise and hare) technique finds the middle in a single pass. This is a foundational pattern used in cycle detection, palindrome checking, and merge sort on linked lists.

Why Slow/Fast Pointers?

Real-World Use Cases

Load balancing: Split a task list in half for two workers.

Merge sort on linked lists: Finding the middle is the key step to divide the list.

Palindrome check: Find the middle, reverse the second half, compare.

Cycle detection (Floyd's): Same slow/fast idea detects loops in linked lists.

The Algorithm

Tortoise and Hare

Use two pointers starting at the head:

• Slow moves 1 step at a time.

• Fast moves 2 steps at a time.

When fast reaches the end (null or last node), slow is at the middle. Why? Fast travels twice as far, so when fast has gone through the whole list, slow has gone exactly halfway.

Time & Space Complexity

Time: O(n) — single pass through the list.

Space: O(1) — only two pointer variables.

Speed

Pseudocode

function middle_node(head):
    slow = head
    fast = head
    while fast is not null AND fast.next is not null:
        slow = slow.next          // 1 step
        fast = fast.next.next     // 2 steps
    return slow                   // slow is at the middle

Walkthrough

Find the middle of [1, 2, 3, 4, 5]:

Step by step

Start:  slow=0(val 1), fast=0(val 1)
Step 1: slow=1(val 2), fast=2(val 3)
Step 2: slow=2(val 3), fast=4(val 5)
fast.next is null → stop. slow is at index 2 (value 3).

Middle node: 3 (the 3rd of 5 nodes).

Even-length list: [1, 2, 3, 4, 5, 6]

Start:  slow=0, fast=0
Step 1: slow=1, fast=2
Step 2: slow=2, fast=4
Step 3: slow=3, fast=6 (null)
fast is null → stop. slow is at index 3 (value 4).

For even-length lists, this returns the second middle node.

Common Pitfalls

1. Null check order matters

Check fast != null before fast.next != null. If fast is null, accessing fast.next crashes.

2. Even vs odd length

For even-length lists, there are two "middle" nodes. This algorithm returns the second one. Some problems want the first — adjust the loop condition accordingly.

What You Learned

Key Takeaways

Slow/fast pointer pattern — one of the most versatile linked list techniques.

Single pass — no need to know the length in advance.

Foundation for harder problems — cycle detection, palindrome check, merge sort split.
