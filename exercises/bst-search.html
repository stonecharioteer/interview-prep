BST: Search

Trees (BST) Beginner
Prerequisites
  • #121 BST: Insert — BST structure and ordering property
  • #37 Binary Search — the halving principle

What You Will Learn

Search for a value in a BST by exploiting the ordering property. At each node, you eliminate half the remaining tree — exactly like binary search on a sorted array, but on a tree structure. Watch nodes fade out as entire subtrees are eliminated!

The Algorithm

How It Works

1. Start at the root.

2. If the current node is null, the value is not in the tree.

3. If the current node's value equals the target, found it!

4. If target < current, search the left subtree (everything right is too big).

5. If target > current, search the right subtree (everything left is too small).

Time & Space Complexity

Time: O(h) — where h = height. O(log n) balanced, O(n) skewed.

Space: O(h) — recursion stack. O(1) iterative.

Contrast: General tree search is O(n) — BST search is O(log n) because it prunes half the tree at each step!

Pseudocode

function search(node, target):
    if node is null:
        return null          // not found
    if target == node.val:
        return node          // found!
    if target < node.val:
        return search(node.left, target)
    else:
        return search(node.right, target)

Walkthrough

Search for 6 in BST [8, 3, 10, 1, 6, 14]

        8
       / \
      3   10
     / \    \
    1   6   14

Search for 6:
  At 8: 6 < 8 → go left (eliminate 10, 14)
  At 3: 6 > 3 → go right (eliminate 1)
  At 6: 6 == 6 → FOUND!

Only visited 3 nodes out of 6!

Search for 5 (not in tree)

Search for 5:
  At 8: 5 < 8 → go left
  At 3: 5 > 3 → go right
  At 6: 5 < 6 → go left
  6.left is null → NOT FOUND

5 would be the left child of 6 if it existed.

Common Pitfalls

1. Searching a general tree like a BST

BST search only works if the tree satisfies the BST property. If the tree is not a BST, you must search all nodes (O(n)).

2. Not handling the null case

Always check for null before accessing a node's value. Reaching null means the value is not in the tree.

What You Learned

Key Takeaways

BST search is binary search on a tree: same halving principle, O(log n) for balanced trees.

Each comparison eliminates a subtree: this is what makes BSTs powerful for lookups.

Not found = reached null: the search ends at an empty child, exactly where the value would be inserted.
