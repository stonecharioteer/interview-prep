Trees: Level-Order Traversal (BFS)

What's New Here

Preorder, inorder, and postorder all use depth-first traversal (go deep before going wide). Level-order traversal is breadth-first: visit all nodes at depth 0, then depth 1, then depth 2, and so on. Instead of a stack (recursion), we use a queue.

Why Level-Order Traversal?

Use Cases

BFS on trees: Finding the shortest path or nearest node in an unweighted tree.

Serialization: Storing a tree level-by-level for reconstruction (e.g., LeetCode's format).

Finding width: Counting nodes at each level to find the widest level.

Heap array: A heap's array representation is exactly the level-order traversal of the tree.

The Algorithm

How It Works

1. Start with the root in a queue.
2. While the queue is not empty: dequeue a node, visit it, then enqueue its left and right children (if they exist).
3. The queue ensures nodes are processed in order of depth.

Time & Space Complexity

Time: O(n) — every node visited once.

Space: O(w) — where w is the maximum width of the tree (the widest level). Worst case O(n/2) for a complete tree's last level.

Pseudocode

function level_order(root):
    if root is null:
        return []
    result = []
    queue = new Queue()
    queue.enqueue(root)
    while queue is not empty:
        node = queue.dequeue()
        result.append(node.value)
        if node.left is not null:
            queue.enqueue(node.left)
        if node.right is not null:
            queue.enqueue(node.right)
    return result

Common Pitfalls

1. Forgetting null checks before enqueueing

Always check node.left and node.right are not null before enqueueing. Otherwise you'll process null as a node.

2. Confusing with DFS

Using a stack gives you DFS (depth-first). Using a queue gives you BFS (breadth-first/level-order). The data structure determines the traversal order.

What You Learned

Key Takeaways

BFS = queue, DFS = stack (or recursion). This is the fundamental distinction.

Level-order visits nodes in breadth-first order — all nodes at depth d before any at depth d+1.

Heap arrays are level-order — this directly connects to the next exercise.
