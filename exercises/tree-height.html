What is Tree Height?

The height of a tree is the number of edges on the longest path from the root to a leaf. An empty tree has height -1, a single node has height 0.

height(node) = 1 + max(height(left), height(right))

Why Height Matters

Height determines the worst-case time for operations that walk root-to-leaf (like search in BST, insert in heap). A balanced tree has height O(log n), giving fast operations. A degenerate tree (linked list shape) has height O(n).

Time & Space

Time: O(n) — visit every node.

Space: O(h) — recursion stack.

function height(node):
