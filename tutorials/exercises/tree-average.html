Trees: Average of All Values

Trees (Binary) Beginner
Prerequisites
  • #110 Tree Sum — summing all values in a tree
  • #80 Tree Size — counting nodes in a tree

What You Will Learn

Compute the average of all node values in a binary tree. This combines two recursive traversals you already know — sum and count — into one pass. Watch how the running average settles toward the true answer as each node is weighed in.

The Algorithm

How It Works

1. Traverse the tree (any order works: preorder, inorder, etc.).

2. At each node, add its value to a running sum and increment a count.

3. After visiting all nodes, return sum / count.

Mental model: imagine placing each node on a scale. The average is the balance point. It wobbles as you add nodes, then settles when all are placed.

Time & Space Complexity

Time: O(n) — visit every node exactly once.

Space: O(h) — recursion stack depth. O(n) worst case (skewed), O(log n) balanced.

Speed

Pseudocode

function treeAverage(root):
    if root is null:
        return 0
    sum = 0
    count = 0

    function traverse(node):
        if node is null: return
        sum += node.val
        count += 1
        traverse(node.left)
        traverse(node.right)

    traverse(root)
    return sum / count

Common Pitfalls

1. Empty tree

If the tree is null, the average is undefined (or 0 by convention). Do not divide by zero.

2. Integer division

In languages like Java or C++, dividing two integers truncates. Use floating-point division to get the correct average.

3. Two-pass vs. one-pass

You could call treeSum() and treeSize() separately (two passes), but a single traversal that tracks both is more efficient. Either approach is O(n).

What You Learned

Key Takeaways

Combine sum and count: Average = sum / count. One traversal can compute both.

Running average settles: Watch how the average wobbles early and converges — this is a useful mental model for streaming averages.

Null check matters: Always handle the empty tree case to avoid division by zero.
