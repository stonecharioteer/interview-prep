Math: GCD (Euclidean Algorithm)

Math Beginner

Starting Point

No prerequisites needed. The Euclidean algorithm is one of the oldest known algorithms, described by Euclid around 300 BCE. It requires only the concept of division with remainder.

What is GCD?

Definition

The Greatest Common Divisor (GCD) of two integers is the largest positive integer that divides both of them evenly. For example, GCD(12, 8) = 4 because 4 is the largest number that divides both 12 and 8.

Also known as the Highest Common Factor (HCF).

Real-World Use Cases

Simplifying fractions: To reduce 12/8 to 3/2, divide both by GCD(12,8)=4.

Cryptography (RSA): RSA key generation requires finding numbers whose GCD with a given value is 1 (coprime).

LCM computation: LCM(a,b) = a*b / GCD(a,b). LCM is used in scheduling problems.

Tiling: The largest square tile that perfectly tiles an a-by-b rectangle has side length GCD(a,b).

The Euclidean Algorithm

How It Works

The key insight: GCD(a, b) = GCD(b, a % b). In each step, replace the larger number with the remainder of dividing the larger by the smaller. Repeat until the remainder is 0. The last non-zero value is the GCD.

Why does this work? If d divides both a and b, then d also divides (a % b). So the set of common divisors never changes across steps — only the numbers shrink.

Complexity

Time: O(log(min(a, b))) — the numbers shrink by at least half every two steps (related to Fibonacci numbers).

Space: O(1) iterative, O(log n) recursive (call stack).

Speed

Pseudocode

function gcd(a, b):
    while b != 0:
        remainder = a % b
        a = b
        b = remainder
    return a

Walkthrough

GCD(48, 18)

Step 1: a=48, b=18. 48 % 18 = 12. Now a=18, b=12.
Step 2: a=18, b=12.  18 % 12 = 6.  Now a=12, b=6.
Step 3: a=12, b=6.   12 % 6  = 0.  Now a=6,  b=0.

b is 0, so GCD = a = 6.

Check: 48 / 6 = 8, 18 / 6 = 3. Both divide evenly.

Common Pitfalls

1. Argument order

GCD(a, b) = GCD(b, a). The algorithm works regardless of which input is larger. If a < b, the first step just swaps them (since a % b = a when a < b).

2. Handling zero

GCD(a, 0) = a. Zero is divisible by everything, so the GCD of any number with 0 is that number itself. GCD(0, 0) is typically defined as 0.

What You Learned

Key Takeaways

The Euclidean algorithm computes GCD by repeatedly applying: GCD(a,b) = GCD(b, a%b).

It runs in O(log n) time — extremely fast even for huge numbers.

GCD is the foundation for simplifying fractions, computing LCM, and cryptographic algorithms.
