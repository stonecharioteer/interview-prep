Finding the Minimum

In a general binary tree (NOT a BST), the minimum could be anywhere. We must check every node.

min(node) = min(node.val, min(left), min(right))

Compare with Array Min (#1)

Array min scans left to right. Tree min recurses through the tree structure. Both are O(n) because you must check everything. In a BST, you could just follow left children for O(h).

Time & Space

Time: O(n) — visit every node.

Space: O(h) — recursion stack.

Pseudocode

function tree_min(node):
    if node is null: return infinity
    return min(node.val, tree_min(node.left), tree_min(node.right))

Walkthrough

Tracing [4,2,7,1,3,5,9]

min(1)=1, min(3)=3 => min(2)=min(2,1,3)=1
min(5)=5, min(9)=9 => min(7)=min(7,5,9)=5
min(4)=min(4,1,5)=1
