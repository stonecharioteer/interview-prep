BST: Validate

Trees (BST) Intermediate
Prerequisites
  • #59 Inorder Traversal — visiting nodes in sorted order

What You Will Learn

Determine whether a binary tree is a valid BST. The key insight: each node has a "passport" with an allowed value range [min, max]. As you descend, the range gets tighter. Going left narrows the max; going right narrows the min. If any node's value falls outside its range, the tree is not a valid BST.

The Algorithm

How It Works

1. Start at the root with range (-infinity, +infinity).

2. At each node, check: is min < node.val < max?

3. If not, the tree is invalid.

4. Recurse left with range (min, node.val) — everything left must be smaller.

5. Recurse right with range (node.val, max) — everything right must be larger.

Time & Space Complexity

Time: O(n) — visit every node once.

Space: O(h) — recursion stack depth.

Pseudocode

function isValidBST(node, min=-inf, max=+inf):
    if node is null:
        return true
    if node.val <= min or node.val >= max:
        return false     // violation!
    return isValidBST(node.left, min, node.val)
       and isValidBST(node.right, node.val, max)

Walkthrough

Valid BST: [8, 3, 10, 1, 6, 14]

        8 range(-inf, +inf): 8 is valid
       / \
      3   10
     / \    \
    1   6   14

  3 range(-inf, 8):  3 is valid
  1 range(-inf, 3):  1 is valid
  6 range(3, 8):     6 is valid
 10 range(8, +inf): 10 is valid
 14 range(10, +inf): 14 is valid
 All nodes valid!

Invalid BST: root=5, left=[3,2,7], right=[8]

        5 range(-inf, +inf): valid
       / \
      3   8
     / \
    2   7 range(3, 5): 7 >= 5 VIOLATION!

 Node 7 is in the left subtree of 5, so it
 must be < 5. But 7 > 5!
 Checking only parent (3 < 7) misses this.

Common Pitfalls

1. Only checking parent-child relationship

The classic bug: checking only that left.val < node.val and right.val > node.val. This misses violations deeper in the tree where a node satisfies its parent but violates an ancestor.

2. Using <= vs < incorrectly

If the BST does not allow duplicates, use strict inequalities. A common mistake is allowing equal values where they should be rejected.

What You Learned

Key Takeaways

Range narrowing is the key insight: each node inherits constraints from ALL ancestors, not just its parent.

The "passport" mental model: each node has an allowed range that gets tighter as you descend.

Alternative approach: inorder traversal of a valid BST produces a sorted sequence. If any element is out of order, it is not a valid BST.
