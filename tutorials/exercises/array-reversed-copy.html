Arrays: Reversed Copy

Arrays Beginner
Prerequisites
  • #1 min — array traversal

What's New Here

This exercise teaches building a new array by reading the source backwards. You learn to traverse in reverse order (high index to low) and understand the O(n) space tradeoff: creating a copy uses extra memory but preserves the original. This contrasts with the in-place approach you'll learn next.

Why Create a Reversed Copy?

Real-World Use Cases

Undo history: Display recent actions in reverse chronological order.

Reverse display: Show a chat log newest-first without modifying the data.

Immutable data: In functional programming, you never modify originals.

Testing: Compare an array with its reverse to check for palindromes.

The Algorithm

How It Works

Create a new empty array. Read the source from the last element to the first, appending each value to the result. The result is the reverse of the source.

Time & Space Complexity

Time: O(n) — visit each element once.

Space: O(n) — the new array is the same size as the original.

Walkthrough

Reverse-copy [1, 2, 3, 4, 5]:

Step by step

Initialize: result = []

Read index 4: value=5 → result = [5]
Read index 3: value=4 → result = [5, 4]
Read index 2: value=3 → result = [5, 4, 3]
Read index 1: value=2 → result = [5, 4, 3, 2]
Read index 0: value=1 → result = [5, 4, 3, 2, 1]

Result: [5, 4, 3, 2, 1]

Pseudocode

function reversed_copy(arr):
    result = []
    for i from len(arr) - 1 down to 0:
        result.append(arr[i])
    return result

Common Pitfalls

1. Off-by-one on the start index

The last valid index is len(arr) - 1, not len(arr). Starting at len(arr) accesses out of bounds.

2. Forgetting this uses O(n) extra space

If memory is tight, consider reversing in-place instead (exercise #26).

What You Learned

Key Takeaways

Reverse traversal — loop from high index to low.

Space tradeoff — O(n) extra memory preserves the original.

Building a new array from a transformation is a core pattern.
