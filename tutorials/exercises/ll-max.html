New Concept: Pattern Reuse with Opposite Comparison

Finding the maximum is structurally identical to finding the minimum. The only change is flipping < to >. Recognizing when an algorithm you already know applies with a small tweak is a core skill in problem solving.

Many algorithms come in natural pairs: min/max, first/last, ascending/descending. Once you have one, you have the other.

Time & Space Complexity

Time: O(n) — must check every node.

Space: O(1) — one tracked variable.

Pseudocode

function max(head):
    if head is null:
        error "empty list"
    current_max = head.value
    curr = head.next
    while curr is not null:
        if curr.value > current_max:
            current_max = curr.value
        curr = curr.next
    return current_max

What You Learned

Key Takeaways

Pattern reuse: max is min with > instead of <.

Recognizing algorithm pairs (min/max, first/last) saves you from solving the same problem twice.
