Trees: Is Symmetric?

Trees (Binary) Intermediate
Prerequisites
  • #72 Level-order Traversal — understanding tree structure level by level

What You Will Learn

A tree is symmetric if it is a mirror image of itself — fold it along the center vertical line, and the left and right halves overlap perfectly. Watch as mirror-pairs are compared simultaneously: blue on the left, gold on the right.

The Algorithm

How It Works

1. A tree is symmetric if its left and right subtrees are mirror images of each other.

2. Two trees are mirrors if:

  • Both are null (base case: mirrors match), OR

  • Their root values are equal, AND

  • left.left mirrors right.right, AND

  • left.right mirrors right.left

Mental model: fold the tree down the middle. Does every node on the left match its mirror on the right?

Time & Space Complexity

Time: O(n) — each node is visited once in the mirror comparison.

Space: O(h) — recursion stack depth.

Pseudocode

function isSymmetric(root):
    if root is null: return true
    return isMirror(root.left, root.right)

function isMirror(left, right):
    if left is null and right is null:
        return true
    if left is null or right is null:
        return false
    if left.val != right.val:
        return false
    return isMirror(left.left, right.right)
       and isMirror(left.right, right.left)

Walkthrough

Symmetric tree [1, 2, 2, 3, 4, 4, 3]

       / \

    3  4 4  3

isMirror(2, 2): values match
  isMirror(3, 3): values match (left.left vs right.right)
  isMirror(4, 4): values match (left.right vs right.left)
All pairs match -> TRUE

Asymmetric tree [1, 2, 2, null, 3, null, 3]

        1
       / \
      2   2
       \   \
       3    3

isMirror(2, 2): values match
  isMirror(null, 3): one null, one not -> FALSE!
Mismatch found -> FALSE

Common Pitfalls

1. Comparing left-left with right-left

The mirror comparison is crossed: left.left pairs with right.right, and left.right pairs with right.left. Getting this wrong checks for equality, not symmetry.

2. Forgetting the null cases

Both null = match. One null + one non-null = mismatch. Handle these before comparing values.

3. Confusing symmetric with identical

Symmetric means mirror-image. Identical means exactly the same. A tree can be identical to itself but not symmetric (if it is not a mirror).

What You Learned

Key Takeaways

Mirror = crossed recursion: Compare left.left with right.right and left.right with right.left.

Fold mental model: Imagine folding the tree along the center. Symmetric means every node overlaps its mirror.

Structure AND values must match: Both the shape and the values must mirror.
