What is Postorder?

Visit Left subtree → Right subtree → Root. Process children before the parent.

Think of it as “clean up children before yourself.” This is exactly how you’d delete a tree: delete children first, then the parent node.

Use Cases

Deleting a tree: Must free children before parent.

Evaluating expression trees: Compute operands before applying the operator.

Computing directory sizes: Sum child sizes before reporting parent total.

Time & Space

Time: O(n) — visit every node once.

Space: O(h) — call stack depth = tree height.

Pseudocode

function postorder(node):
    if node is null: return
    postorder(node.left)
    postorder(node.right)
    visit(node)           // process AFTER children

Walkthrough

Tracing [1,2,3,4,5,6,7]

postorder(1)
  postorder(2)
    postorder(4) → visit 4
    postorder(5) → visit 5
  visit 2
  postorder(3)
    postorder(6) → visit 6
    postorder(7) → visit 7
  visit 3
visit 1
