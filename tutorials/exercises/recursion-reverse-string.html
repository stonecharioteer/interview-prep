EXERCISE #19

Recursion: Reverse String

Recursion Beginner
Prerequisites
  • #16 Factorial — understanding base case and recursive case
  • #18 Sum Array — recursion on sequences

What You Will Learn

This exercise shows how to build up a result string through recursive concatenation. Instead of adding numbers, you peel off the first character, recurse on the rest, and append the character to the end of the recursive result. This reverses the string.

The Recursive Approach

Definition

To reverse a string recursively: if the string is empty or has one character, return it (base case). Otherwise, reverse everything after the first character, then append the first character at the end.

Base case: empty string or single character → return as-is

Recursive case: reverse(str[1..end]) + str[0]

Why Learn This?

Real-World Use Cases

String manipulation: Understanding recursive string operations is foundational for many text-processing algorithms.

Palindrome checking: Reversing a string and comparing it to the original is a common palindrome test.

Interview preparation: Recursive string reversal is a frequent warm-up question in coding interviews.

Time & Space Complexity

Time: O(n²) — string concatenation creates a new string at each level, each up to O(n) in length.

Space: O(n) — n frames on the call stack.

Note: An iterative approach with array swaps achieves O(n) time.

Speed

Pseudocode

function reverse(str):
    if length of str <= 1:       // base case
        return str
    first = str[0]
    rest  = str[1..end]
    return reverse(rest) + first   // append first char at end

Walkthrough

Step by step: reverse("hello")

Building call stack:
  reverse("hello") = reverse("ello") + "h"
  reverse("ello")  = reverse("llo")  + "e"
  reverse("llo")   = reverse("lo")   + "l"
  reverse("lo")    = reverse("o")    + "l"
  reverse("o")     = "o"             ← base case

Unwinding:
  reverse("o")     = "o"
  reverse("lo")    = "o"  + "l" = "ol"
  reverse("llo")   = "ol" + "l" = "oll"
  reverse("ello")  = "oll" + "e" = "olle"
  reverse("hello") = "olle" + "h" = "olleh"

Common Pitfalls

1. Concatenation order matters

It must be reverse(rest) + first, not first + reverse(rest). The latter would return the original string unchanged.

2. O(n²) hidden cost

Each string concatenation creates a new string. With n levels of recursion and strings up to length n, total work is O(n²). For performance-critical code, use an array-based approach.

3. Empty string base case

Make sure your base case handles both empty strings and single characters. Missing the empty string case can cause infinite recursion on edge inputs.

What You Learned

Key Takeaways

Recursive string building: Peel off a character, recurse on the rest, and concatenate in the desired order.

Order of concatenation: Placing the peeled character at the end produces reversal.

Efficiency awareness: This recursive approach is O(n²) due to string concatenation. Recognizing hidden costs is an important skill.
