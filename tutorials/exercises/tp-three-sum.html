Two Pointers: Three Sum

Two Pointers Advanced
Prerequisites
  • #62 two_sum_sorted — two-pointer technique on sorted arrays
  • #30 is_sorted — understanding sorted order and why we sort first

What's New Here

Three Sum extends Two Sum Sorted: find all unique triplets (a, b, c) where a + b + c = 0. The trick: sort the array, then for each element, run two-pointer search on the remaining elements. Sorting also makes it easy to skip duplicates.

The Algorithm

Sort + Fix + Two-Pointer

1. Sort the array.

2. Fix element arr[i] for each i from 0 to n-3.

3. Two-pointer search in arr[i+1..n-1] for a pair summing to -arr[i].

4. Skip duplicates: if arr[i] == arr[i-1], skip to avoid duplicate triplets.

Time & Space Complexity

Time: O(n²) — sorting is O(n log n), the nested loop is O(n²), which dominates.

Space: O(1) extra — aside from the output and sorting overhead.

This is optimal for three sum — you cannot do better than O(n²) for this problem.

Pseudocode

function three_sum(arr):
    sort(arr)
    result = []
    for i from 0 to len(arr) - 3:
        if i > 0 and arr[i] == arr[i-1]:
            continue                      // skip duplicate fixed element
        L = i + 1
        R = len(arr) - 1
        while L < R:
            sum = arr[i] + arr[L] + arr[R]
            if sum == 0:
                result.append([arr[i], arr[L], arr[R]])
                while L < R and arr[L] == arr[L+1]: L++   // skip dup
                while L < R and arr[R] == arr[R-1]: R--   // skip dup
                L++; R--
            else if sum < 0:
                L++
            else:
                R--
    return result

Walkthrough

Find all triplets in [-1, 0, 1, 2, -1, -4] that sum to 0:

Step by step

Sort: [-4, -1, -1, 0, 1, 2]

i=0, fix -4: L=1, R=5. -4+(-1)+2 = -3 < 0 → L++.
  L=2, R=5. -4+(-1)+2 = -3 < 0 → L++.
  L=3, R=5. -4+0+2 = -2 < 0 → L++.
  L=4, R=5. -4+1+2 = -1 < 0 → L++. L crosses R. Done with i=0.

i=1, fix -1: L=2, R=5. -1+(-1)+2 = 0 → Found [-1,-1,2]! L=3, R=4.
  L=3, R=4. -1+0+1 = 0 → Found [-1,0,1]! L=4, R=3. Done.

i=2, fix -1: skip (duplicate of i=1).

Result: [[-1,-1,2], [-1,0,1]]

Common Pitfalls

1. Forgetting to skip duplicates

Without duplicate-skipping, [-1,-1,0,1] would produce [-1,0,1] twice.

2. Not sorting first

Two pointers requires sorted data. Without sorting, the L/R convergence logic is invalid.

3. Early termination

If arr[i] > 0, you can break early: three positive numbers can never sum to 0.

What You Learned

Key Takeaways

Reduce to a solved problem — three sum reduces to two sum sorted for each fixed element.

Sort + two pointers — a powerful combination for n-sum problems.

Duplicate handling — sorting makes duplicates adjacent and easy to skip.
