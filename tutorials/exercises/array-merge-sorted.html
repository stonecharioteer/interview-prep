What's New Here

This exercise introduces the two-pointer merge technique: using one pointer per input array, always advancing the one pointing to the smaller element. Both inputs must be sorted. The result is a new sorted array containing all elements from both inputs. This is the foundation for merge sort, one of the most important sorting algorithms.

Why Merge Sorted Arrays?

Real-World Use Cases

Combining sorted search results: Merge results from multiple sorted indexes into one ranked list.

Merging database query results: Sort-merge join combines two sorted tables on a key.

Merge step in merge sort: The divide step splits; this merge step combines sorted halves back together.

The Algorithm

How It Works

Use pointer i for array A and j for array B. Compare A[i] and B[j]: append the smaller one to the result and advance that pointer. When one array is exhausted, append the remainder of the other.

Time & Space Complexity

Time: O(n + m) where n and m are the lengths of the two arrays.

Space: O(n + m) for the result array.

Walkthrough

Merge A = [1, 3, 5, 7] and B = [2, 4, 6, 8]:

Step by step

i=0, j=0: A[0]=1 ≤ B[0]=2 → take 1 from A. i=1.
i=1, j=0: A[1]=3 > B[0]=2  → take 2 from B. j=1.
i=1, j=1: A[1]=3 ≤ B[1]=4 → take 3 from A. i=2.
i=2, j=1: A[2]=5 > B[1]=4  → take 4 from B. j=2.
i=2, j=2: A[2]=5 ≤ B[2]=6 → take 5 from A. i=3.
i=3, j=2: A[3]=7 > B[2]=6  → take 6 from B. j=3.
i=3, j=3: A[3]=7 ≤ B[3]=8 → take 7 from A. i=4.
A exhausted. Append remaining B: [8].

Result: [1, 2, 3, 4, 5, 6, 7, 8]

Pseudocode

function merge_sorted(A, B):
    result = []
    i = 0
    j = 0
    while i < len(A) and j < len(B):
        if A[i] ≤ B[j]:
            result.append(A[i])
            i = i + 1
        else:
            result.append(B[j])
            j = j + 1
    // Append leftovers
    while i < len(A):
        result.append(A[i])
        i = i + 1
    while j < len(B):
        result.append(B[j])
        j = j + 1
    return result

Common Pitfalls

1. Forgetting the leftover elements

When the main loop ends, one array still has remaining elements. You must append them all. This is the most common bug.

2. Using < instead of ≤

Using ≤ preserves the relative order of equal elements (stability). This matters for merge sort.

3. Assuming equal-length arrays

The two arrays can have different lengths. The algorithm handles this naturally because the leftover loop appends whatever remains.

What You Learned

Key Takeaways

Two-pointer merge — one pointer per sorted input, always take the smaller.

O(n + m) time — each element is touched exactly once.

Core subroutine — this is the heart of merge sort.
