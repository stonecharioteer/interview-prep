What is Frequency Counting?

The Pattern

Frequency counting answers the question: "How many times does each item appear?" You iterate through a collection, and for each item you encounter, you increment its count in a map.

The core operation is: get the current count (defaulting to 0 if the key is new), add 1, and store it back. 

counts[item] = get_or_default(counts, item, 0) + 1

Real-World Use Cases

Word frequency: Count how often each word appears in a document (search engines, text analysis).

Vote counting: Tally votes for candidates in an election.

Histogram building: Count pixel intensities in an image, or score distributions in a class.

Inventory tracking: Count items by category in a warehouse.

Log analysis: Count error types across server logs.

Complexity

Time: O(n) — one pass through the input, each map operation is O(1) average.

Space: O(k) — where k is the number of distinct items (at most n).

What This Exercise Teaches

New Concept: Building State Incrementally

In #42, you learned to read from a map safely. Now you learn to build a map from data. This "accumulate into a map" pattern is one of the most common operations in programming.

The key insight: you do not need to know all the keys in advance. The map grows organically as you encounter new items.

Pseudocode

function count_frequencies(items):
    counts = {}
    for each item in items:
        current = get_or_default(counts, item, 0)
        counts[item] = current + 1
    return counts

Walkthrough

Counting ["apple", "banana", "apple", "cherry", "banana", "apple"]

Process "apple":   counts = {"apple": 1}       (new key)
Process "banana":  counts = {"apple": 1, "banana": 1}  (new key)
Process "apple":   counts = {"apple": 2, "banana": 1}  (incremented)
Process "cherry":  counts = {"apple": 2, "banana": 1, "cherry": 1}  (new key)
Process "banana":  counts = {"apple": 2, "banana": 2, "cherry": 1}  (incremented)
Process "apple":   counts = {"apple": 3, "banana": 2, "cherry": 1}  (incremented)

Result: apple appears 3 times, banana 2, cherry 1.

Common Pitfalls

1. Forgetting to handle the first occurrence

Without get_or_default, accessing counts["apple"] when "apple" is not yet in the map will throw an error or return undefined. Always default to 0 for the first occurrence.

2. Case sensitivity

"Apple" and "apple" are different keys in most maps. Normalize keys (e.g., to lowercase) before counting if you want case-insensitive frequency.

What You Learned

Key Takeaways

Frequency counting is "get_or_default + increment" in a loop.

Maps grow dynamically — you do not need to pre-declare all keys.

This pattern turns an unsorted list into a summary of its contents in O(n) time.
