Arrays: Reverse In Place

Arrays Intermediate
Key prerequisite for Heaps and Sorting. The two-pointer swap technique introduced here is used in heap operations, partitioning (quicksort), and many other algorithms. Master this pattern well.
Prerequisites
  • #23 reversed_copy — understanding reversal with O(n) space

What's New Here

The reversed copy used O(n) extra space. This exercise teaches the two-pointer swap technique: place one pointer at the start, one at the end, swap their elements, then move both pointers inward. This achieves reversal in O(1) extra space — modifying the array in place.

The two-pointer technique is one of the most important patterns in algorithms. It appears in partitioning, palindrome checking, merging, and the "triple reverse" trick for rotation.

Why Reverse In Place?

Real-World Use Cases

Memory efficiency: When you can't afford to allocate a second array.

Palindrome prep: Reverse and compare to the original.

In-place transforms: Many algorithms (like array rotation) use reversal as a subroutine.

Heap operations: Swapping elements is the core of heapify.

The Algorithm

How It Works

Set pointer L = 0 (left end) and R = len(arr) - 1 (right end). While L < R: swap arr[L] and arr[R], then increment L and decrement R. When the pointers meet or cross, you're done.

Time & Space Complexity

Time: O(n) — each element is involved in at most one swap.

Space: O(1) — only a temporary variable for swapping.

Walkthrough

Reverse [1, 2, 3, 4, 5, 6] in place:

Step by step

L=0, R=5: swap arr[0] and arr[5] → [6, 2, 3, 4, 5, 1]
L=1, R=4: swap arr[1] and arr[4] → [6, 5, 3, 4, 2, 1]
L=2, R=3: swap arr[2] and arr[3] → [6, 5, 4, 3, 2, 1]
L=3, R=2: L ≥ R, stop.

Result: [6, 5, 4, 3, 2, 1]

Pseudocode

function reverse_in_place(arr):
    left = 0
    right = len(arr) - 1
    while left < right:
        swap arr[left] and arr[right]
        left = left + 1
        right = right - 1

Common Pitfalls

1. Using ≤ instead of <

The loop condition must be left < right. If you use ≤, when both pointers are on the same element, you'd swap it with itself (harmless but wasteful), and then cross, causing an infinite loop or extra work.

2. Forgetting the temp variable

Swapping requires a temporary: temp = arr[L]; arr[L] = arr[R]; arr[R] = temp. Some languages support tuple unpacking as a shortcut.

3. Odd-length arrays

The middle element doesn't need swapping. The left < right condition naturally skips it when both pointers converge to the center.

What You Learned

Key Takeaways

Two-pointer technique — converging pointers from both ends.

In-place modification — O(1) extra space by swapping elements.

Swap is fundamental — it's the building block for heaps, sorting, and partitioning.
