Sum of All Nodes

sum(node) = node.val + sum(left) + sum(right)

Like tree-size but adding values instead of counting 1 per node.

Time & Space

Time: O(n) — visit every node.

Space: O(h) — recursion stack.

Speed

Pseudocode

function tree_sum(node):
    if node is null: return 0
    return node.val + tree_sum(node.left) + tree_sum(node.right)

Walkthrough

Tracing [4,2,7,1,3,5,9]

sum(1)=1, sum(3)=3 => sum(2)=2+1+3=6
sum(5)=5, sum(9)=9 => sum(7)=7+5+9=21
sum(4)=4+6+21=31
