Linked Lists: Remove First Occurrence

Linked Lists Intermediate
Prerequisites
  • #24 append — node creation and linking

New Concept: Pointer Rewiring

Removing a node from a linked list means making the previous node's next pointer skip over the removed node. The removed node becomes unreachable and can be garbage collected.

This requires tracking two pointers: prev (the node before) and curr (the node to potentially remove). When you find the target, set prev.next = curr.next.

Special case: if the head itself is the target, there is no prev. Just update the head to head.next.

Time & Space Complexity

Time: O(n) — worst case, target is the last node or absent.

Space: O(1) — two pointers.

Pseudocode

function remove_first(head, target):
    if head is null:
        return null
    if head.value == target:
        return head.next           // skip head
    prev = head
    curr = head.next
    while curr is not null:
        if curr.value == target:
            prev.next = curr.next  // skip over curr
            return head
        prev = curr
        curr = curr.next
    return head                    // target not found

Common Pitfalls

1. Forgetting the head case

If the head is the target, there is no "previous" node. Handle this separately.

2. Only removing the first occurrence

This removes only the first match. If you need to remove all, you must continue scanning (a different algorithm).

What You Learned

Key Takeaways

Pointer rewiring (prev.next = curr.next) is how you "delete" from a linked list.

The prev/curr two-pointer pattern is essential for any operation that needs to modify links.

The head is a special case because it has no predecessor.
