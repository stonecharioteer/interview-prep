DP: Climbing Stairs

Dynamic Programming Beginner
Prerequisites
  • #99 Fibonacci Tabulation — bottom-up DP that this problem secretly is

What You Will Learn

You are climbing a staircase with n steps. At each step, you can climb 1 or 2 steps. How many distinct ways can you reach the top? This is one of the most popular DP interview questions — and the punchline is that it is Fibonacci in disguise.

Problem Statement

Climbing Stairs

Given n steps, you start at step 0 (ground). At each position, you can take 1 step or 2 steps. Count the number of distinct ways to reach step n.

Example: n = 3 → 3 ways: (1+1+1), (1+2), (2+1).

Example: n = 4 → 5 ways: (1+1+1+1), (1+1+2), (1+2+1), (2+1+1), (2+2).

Why It Is Fibonacci

The Key Insight

To reach step n, you either came from step n-1 (took 1 step) or step n-2 (took 2 steps). So:

ways(n) = ways(n-1) + ways(n-2)

That is exactly the Fibonacci recurrence! With base cases: ways(0) = 1 (one way to stay at ground) and ways(1) = 1 (one way to reach step 1). The answer for n steps is fib(n+1).

Many DP problems are Fibonacci in disguise. Whenever you see “at each step, choose between 2 options, count total ways”, think Fibonacci.

Time & Space Complexity

Time: O(n) — fill dp table from 0 to n.

Space: O(n) — the dp array. (Optimizable to O(1) with two variables.)

Speed

Pseudocode

function climbing_stairs(n):
    dp = array of size n+1
    dp[0] = 1   // one way to stand at ground
    dp[1] = 1   // one way to reach step 1
    for i from 2 to n:
        dp[i] = dp[i-1] + dp[i-2]
    return dp[n]

Walkthrough

Climbing 6 stairs

dp[0] = 1   (base: standing at ground)
dp[1] = 1   (base: one way to reach step 1)
dp[2] = dp[1] + dp[0] = 1 + 1 = 2
dp[3] = dp[2] + dp[1] = 2 + 1 = 3
dp[4] = dp[3] + dp[2] = 3 + 2 = 5
dp[5] = dp[4] + dp[3] = 5 + 3 = 8
dp[6] = dp[5] + dp[4] = 8 + 5 = 13

Answer: 13 distinct ways to climb 6 stairs.

Compare: fib(7) = 13. Climbing stairs(n) = fib(n+1)!

Common Pitfalls

1. Base case confusion

dp[0] = 1, not 0. There is exactly one way to be at the ground: do nothing. This is the “empty way” and it is essential for the recurrence to work.

2. Not recognizing the pattern

In interviews, the key insight is recognizing that this is Fibonacci. If you start writing a brute-force solution, you will time out. Always look for the recurrence first.

3. Trying to enumerate all paths

Do not try to list all paths. The question asks for the count, not the paths themselves. The dp recurrence gives you the count directly in O(n).

What You Learned

Key Takeaways

Climbing stairs = Fibonacci: dp[i] = dp[i-1] + dp[i-2] with dp[0] = dp[1] = 1.

Recognizing patterns is key: Many DP problems reduce to known recurrences. Train yourself to spot the Fibonacci pattern.

The DP recipe works: 1. Define dp[i] = number of ways to reach step i. 2. Recurrence: dp[i] = dp[i-1] + dp[i-2]. 3. Base cases. 4. Fill the table.
