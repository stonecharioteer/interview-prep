Arrays: Sum of Elements

Arrays Beginner
Prerequisites

What's New Here

In min/max, you compared each element against a tracked value. Here you introduce the accumulator pattern: instead of comparing, you add each element to a running total. The accumulator starts at 0 (the identity for addition) rather than arr[0]. This pattern generalizes to products, string concatenation, and any fold operation.

Why Compute a Sum?

Real-World Use Cases

Financial totals: Summing transactions, invoices, or expenses.

Batch processing: Total bytes transferred, total items shipped.

Physics simulations: Summing forces acting on an object.

Statistics: Sum is the first step in computing averages, variance, and standard deviation.

The Algorithm

How It Works

Initialize an accumulator to 0. Walk through every element, adding each value to the accumulator. When done, the accumulator holds the total sum.

Key difference from min/max: there is no comparison — every element contributes to the result unconditionally.

Time & Space Complexity

Time: O(n) — every element must be visited once.

Space: O(1) — one accumulator variable.

Let's trace the sum of [10, 20, 30, 40, 50]:

Step by step

Initialize: sum = 0
Index 0: sum = 0 + 10  = 10
Index 1: sum = 10 + 20 = 30
Index 2: sum = 30 + 30 = 60
Index 3: sum = 60 + 40 = 100
Index 4: sum = 100 + 50 = 150

Result: sum is 150.

Pseudocode

function sum(arr):
    total = 0
    for i from 0 to len(arr) - 1:
        total = total + arr[i]
    return total

Common Pitfalls

1. Integer overflow

If the array is large or values are big, the sum can exceed the maximum integer size in some languages. Consider using a larger numeric type if needed.

2. Starting at arr[0] instead of 0

Unlike min/max, the accumulator for sum starts at 0 (the additive identity). If you start at arr[0] and loop from index 1, it also works — but starting at 0 and looping from index 0 is simpler and handles empty arrays naturally (sum of nothing is 0).

3. Floating-point precision

When summing decimal numbers, small rounding errors accumulate. For financial calculations, use integer arithmetic (cents instead of dollars) or specialized decimal types.

What You Learned

Key Takeaways

The accumulator pattern — initialize a variable, update it every iteration.

Identity values — sum starts at 0, product starts at 1, concatenation starts at "".

Every element contributes — there is no conditional skip like in min/max.
