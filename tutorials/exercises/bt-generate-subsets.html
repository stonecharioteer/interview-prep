Backtracking: Generate All Subsets

Backtracking Intermediate
Prerequisites
  • #16 factorial — basic recursion and base cases
  • #53 preorder traversal — traversing a tree recursively

What's New Here

This is your first backtracking problem. Unlike simple recursion (which computes a single result), backtracking explores all possible choices and collects every valid solution. For subsets, at each element you make a binary decision: include it or exclude it. This creates a binary decision tree of depth n, producing 2n subsets.

Why Backtracking?

Use Cases

Power set: Enumerate all possible combinations (feature selection, testing).

Combination sum: Find all subsets whose elements sum to a target.

Permutations: Same backtracking idea, different branching logic.

Constraint satisfaction: Sudoku, N-Queens, graph coloring — all use backtracking.

The Algorithm

How It Works (Binary Decision Tree)

At index i, you have two choices:
1. Include arr[i] in the current subset, then recurse on i+1.
2. Exclude arr[i], then recurse on i+1.
Base case: when i == n, the current subset is a complete solution — add it to results.

The "backtracking" part: after exploring the "include" branch, you undo (remove the element) and explore the "exclude" branch.

Time & Space Complexity

Time: O(n × 2n) — 2n subsets, each takes O(n) to copy.

Space: O(n) — recursion depth is n. Output storage is O(n × 2n).

Walkthrough

Generate all subsets of [1, 2, 3]:

Decision tree

                    []
                  /      \
               [1]        []
              /    \     /    \
           [1,2]  [1]  [2]    []
           / \    / \   / \   / \
       [1,2,3][1,2][1,3][1][2,3][2][3][]

Subsets (at leaves): [1,2,3], [1,2], [1,3], [1], [2,3], [2], [3], []
Total: 2^3 = 8 subsets.

Pseudocode

function generate_subsets(arr):
    result = []
    backtrack(arr, 0, [], result)
    return result

function backtrack(arr, index, current, result):
    if index == len(arr):
        result.append(copy of current)    // leaf: record subset
        return

    // Choice 1: include arr[index]
    current.append(arr[index])
    backtrack(arr, index + 1, current, result)

    // Choice 2: exclude arr[index] (backtrack!)
    current.pop()                          // undo the include
    backtrack(arr, index + 1, current, result)

Common Pitfalls

1. Forgetting to copy the subset

At the base case, you must add a copy of the current list. If you add a reference, all entries in the result will point to the same (eventually empty) list.

2. Not undoing the choice (the "backtrack" step)

After exploring the "include" branch, you must pop() the element before exploring the "exclude" branch. This is the defining characteristic of backtracking.

3. Generating duplicates with duplicate elements

If the input has duplicates (e.g., [1, 2, 2]), sort first and skip consecutive duplicates at the same decision level.

What You Learned

Key Takeaways

Backtracking = recursion + undo. Explore one branch, undo, explore the other.

The decision tree is a mental model: each level is a decision point, each path from root to leaf is one solution.

Subset generation is the foundation for combination sum, permutations, and constraint-satisfaction problems.
