Sorting: Selection Sort

Sorting Beginner
Prerequisites
  • #1 min — finding the minimum element
  • #30 bubble_sort — your first sorting algorithm

Why Selection Sort?

Use Cases

Minimizing swaps: Selection sort does at most n-1 swaps total. If swapping is expensive (e.g., moving large records), this matters.

Education: It demonstrates the "find minimum, place it" pattern clearly.

Memory-constrained systems: Like bubble sort, it works entirely in-place with O(1) extra memory.

What New Concept Does This Teach?

Selection sort teaches the find-minimum-and-swap pattern. You already know how to find a minimum (Exercise #1). Now you apply that skill repeatedly to build a sorted array from left to right. The key insight: instead of bubbling elements one step at a time, you select the right element and place it directly.

How It Works

The Algorithm

Divide the array into two parts: a sorted portion (initially empty, growing from the left) and an unsorted portion (initially the whole array, shrinking).

For each position from left to right: scan the unsorted portion to find the minimum, then swap it into the current position. That element is now in its final place.

Time & Space Complexity

Time: O(n²) always — even on sorted arrays, it still scans for the minimum each pass.

Space: O(1) — in-place sorting.

Swaps: O(n) — at most n-1 swaps, far fewer than bubble sort's O(n²) worst case.

Speed

Pseudocode

function selection_sort(arr):
    n = length(arr)
    for i from 0 to n - 2:
        min_idx = i
        for j from i + 1 to n - 1:
            if arr[j] < arr[min_idx]:
                min_idx = j
        if min_idx != i:
            swap(arr[i], arr[min_idx])

Walkthrough

Let's trace sorting [29, 10, 14, 37, 13]:

Step by step

Pass 1: Find min in [29,10,14,37,13] → 10 at index 1
  Swap arr[0] and arr[1] → [10,29,14,37,13]
Pass 2: Find min in [29,14,37,13] → 13 at index 4
  Swap arr[1] and arr[4] → [10,13,14,37,29]
Pass 3: Find min in [14,37,29] → 14 at index 2
  Already in place, no swap.
Pass 4: Find min in [37,29] → 29 at index 4
  Swap arr[3] and arr[4] → [10,13,14,29,37]
Done! Sorted with only 3 swaps.

Common Pitfalls

1. Not unstable

Selection sort is not stable. Equal elements may change relative order after swaps. Example: sorting [5a, 3, 5b] produces [3, 5b, 5a].

2. Always O(n²)

Unlike bubble sort, there is no early-exit optimization. Selection sort always scans the unsorted portion fully, even if the array is already sorted.

What You Learned

Key Takeaways

Find-min-and-place is a fundamental pattern reused in heaps and priority queues.

Minimizing swaps can matter when move operations are expensive.

Sorted/unsorted partition is a concept shared with insertion sort.
