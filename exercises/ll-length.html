Linked Lists: Finding the Length

Linked Lists Beginner
Prerequisites

New Concept: What Is a Linked List?

A linked list is a sequence of nodes. Each node holds a value and a pointer (reference) to the next node. The last node points to null, meaning "there is no next node."

Unlike arrays, nodes are not stored contiguously in memory. You cannot jump to position 5 directly — you must start at the head (the first node) and follow pointers one by one.

Arrays vs. Linked Lists

Array: Random access O(1), insert/delete at middle O(n), fixed or costly resizing.

Linked list: Sequential access O(n), insert/delete at head O(1), dynamic sizing with no wasted space.

Linked lists shine when you frequently insert or remove elements at the beginning or middle, or when you don't know the total size upfront.

Why Find the Length?

Use Cases

Validation: Checking if a list has enough elements before processing.

Dynamic collections: When elements are added/removed frequently and you need a count.

Foundation: Length is the simplest linked list traversal — the pattern you learn here (follow pointers until null) is the basis of every linked list algorithm.

The Algorithm: Walk and Count

How It Works

Start at the head. Set a counter to 0. For each node you visit, increment the counter and move to the next node. When you reach null, the counter holds the length.

This is the linked list traversal pattern: start at head, follow next pointers until null.

Time & Space Complexity

Time: O(n) — you must visit every node. There is no shortcut because linked lists don't store their length.

Space: O(1) — only one counter variable.

Walkthrough

Tracing length of [10, 20, 30, 40]:

Step by step

curr = head (10), count = 0
Visit node 10: count = 1, move to next
Visit node 20: count = 2, move to next
Visit node 30: count = 3, move to next
Visit node 40: count = 4, move to next
curr = null, stop.

Result: length is 4.

Pseudocode

function length(head):
    count = 0
    curr = head
    while curr is not null:
        count = count + 1
        curr = curr.next
    return count

Common Pitfalls

1. Empty list

If head is null, the loop never runs and count stays 0. This is correct — no special case needed.

2. Off-by-one

Make sure you count the node before advancing to next, or initialize count to match your loop structure.

What You Learned

Key Takeaways

Linked lists store elements in non-contiguous nodes connected by pointers.

Traversal (head to null) is the fundamental pattern for all linked list operations.

No random access — unlike arrays, you must walk through nodes sequentially.
