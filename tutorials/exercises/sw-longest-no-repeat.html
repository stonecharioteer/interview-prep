Longest Substring Without Repeating Characters

Sliding Window Intermediate

The Problem

Definition

Given a string, find the length of the longest substring without any repeating characters.

Input:  "abcabcbb"
Output: 3  (substring "abc")

One of the Most Common Interview Questions

This problem appears frequently in coding interviews at major companies. It's a natural extension of the K-distinct problem: here every character in the window must be unique (i.e., all characters are distinct).

The Approach

Sliding Window + Set

Maintain a set of characters in the current window. Expand right. When a duplicate is found, shrink from the left until the duplicate is removed.

def longest_no_repeat(s):
    seen = set()
    left = 0
    best = 0

    for right in range(len(s)):
        while s[right] in seen:
            seen.remove(s[left])
            left += 1
        seen.add(s[right])
        best = max(best, right - left + 1)

    return best

Optimization: Jump Left Directly

Instead of shrinking one character at a time, store the last index of each character. When you find a duplicate, jump left directly past it:

def longest_no_repeat_fast(s):
    last_seen = {}
    left = 0
    best = 0
    for right in range(len(s)):
        if s[right] in last_seen and last_seen[s[right]] >= left:
            left = last_seen[s[right]] + 1
        last_seen[s[right]] = right
        best = max(best, right - left + 1)
    return best

Complexity

Time: O(n) — each character is visited at most twice (once by right, once by left).

Space: O(min(n, alphabet)) — the set holds at most the size of the character set.

Common Pitfalls

1. Using the wrong data structure

A set checks membership in O(1). Don't use a list (O(n) lookup) or you'll get O(n²).

2. Off-by-one in the optimized version

When using last_seen, check last_seen[c] ≥ left. A previous occurrence before left is outside the window and doesn't count as a duplicate.
