Two Pointers: Two Sum (Sorted Array)

Two Pointers Intermediate
Prerequisites
  • #61 two_sum — hash map approach for unsorted arrays
  • #37 binary_search — leveraging sorted order

What's New Here

In #61 you used a hash map for O(n) time but O(n) space. When the array is already sorted, you can do better on space: use two pointers (left and right) that walk inward, achieving O(n) time with O(1) space. No extra data structure needed.

Why Two Pointers?

The Key Insight

Start with L=0 (smallest) and R=n-1 (largest). Compute sum = arr[L] + arr[R]:

• If sum equals target: found it!

• If sum is too small: move L right (need a bigger value).

• If sum is too large: move R left (need a smaller value).

Because the array is sorted, each pointer move eliminates one candidate. They meet in at most n steps.

Time & Space Complexity

Time: O(n) — each step moves L or R, and they converge.

Space: O(1) — only two index variables.

Speed

Pseudocode

function two_sum_sorted(arr, target):
    L = 0
    R = len(arr) - 1
    while L < R:
        sum = arr[L] + arr[R]
        if sum == target:
            return [L, R]
        else if sum < target:
            L = L + 1            // need bigger sum
        else:
            R = R - 1            // need smaller sum
    return []                    // no pair found

Walkthrough

Find two numbers in [1, 3, 5, 7, 11, 13] that sum to 12:

Step by step

L=0, R=5: arr[0]+arr[5] = 1+13 = 14 > 12 → R=4.
L=0, R=4: arr[0]+arr[4] = 1+11 = 12 == 12 → Found! Return [0, 4].

Only 2 comparisons. The sorted order lets us prune efficiently.

Why This Works

Correctness Argument

When sum > target, moving R left is safe: arr[R] paired with any element ≥ arr[L] would be even larger. So arr[R] cannot be part of the answer — we eliminate it. Similarly, when sum < target, arr[L] paired with anything ≤ arr[R] is too small. We never skip a valid answer.

Common Pitfalls

1. Forgetting the array must be sorted

Two pointers only work on sorted arrays. On unsorted data, use the hash map approach (#61).

2. Using ≤ instead of < in the loop condition

Use L < R (strict). If L == R, you'd be using the same element twice.

What You Learned

Key Takeaways

Two pointers on sorted data — a fundamental pattern for O(n) time, O(1) space.

Sorted order = free information — it tells you which direction to move.

Foundation for three_sum — fix one element, then two-pointer on the rest.
