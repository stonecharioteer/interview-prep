New Concept: Accumulator Pattern on Linked Lists

In the min/max exercises, you tracked a "best so far" value. Here you track a running total — an accumulator. Instead of comparing, you add each node's value to the accumulator.

The accumulator pattern is fundamental: summation, product, string concatenation, and many reduce-style operations all follow this shape.

Time & Space Complexity

Time: O(n) — every node contributes to the sum.

Space: O(1) — one accumulator variable.

Pseudocode

function sum(head):
    total = 0
    curr = head
    while curr is not null:
        total = total + curr.value
        curr = curr.next
    return total

What You Learned

Key Takeaways

The accumulator pattern: initialize to identity element (0 for addition), combine each value.

Unlike min/max, sum starts at 0, not the first element. An empty list has sum 0.

This pattern generalizes to product (start at 1), concatenation (start at empty string), etc.
