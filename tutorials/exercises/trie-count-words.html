Trie: Count Total Words

Trie Beginner
Required Learning
  • #82 Trie: insert — building a trie
  • #92 Trie: search — finding words in a trie

The Problem

Definition

Count the total number of words stored in a trie. A word is any path from the root to a node marked with is_end = true.

Mental Model: Census Taker

Think of yourself as a census taker walking through every street in a city (the trie). Each time you encounter a house with a mailbox (a node with is_end), you add one to your count. You visit every single street, but you only count the houses, not the intersections.

How It Works

Simple DFS Traversal

Starting from the root, traverse every node in the trie using DFS or BFS. Maintain a counter. Every time you visit a node where is_end = true, increment the counter.

def count_words():
    count = 0
    stack = [root]
    while stack:
        node = stack.pop()
        if node.is_end:
            count += 1
        for child in node.children.values():
            stack.append(child)
    return count

Complexity

Time: O(n) where n = total number of nodes in the trie. Must visit every node.

Space: O(n) for the stack/queue in the worst case (wide trie).

Common Pitfalls

1. Counting nodes instead of words

Not every node represents a word. Only nodes with is_end = true are word endings. A trie with "car" and "card" has 5 nodes (including root) but only 2 words.

2. Missing shared-prefix words

If "car" and "card" are both in the trie, the 'r' node has is_end=true (for "car") AND has a child 'd'. Don't skip counting 'r' just because it has children.
