Bits: Count Set Bits (Hamming Weight)

Bits Beginner
Prerequisites
  • #35 is_power_of_two — binary representation and the n & (n-1) trick

Why Count Set Bits?

Use Cases

Error detection: The Hamming weight is used in error-correcting codes to measure the distance between codewords.

Population count: CPUs have a dedicated POPCNT instruction because this operation is so common in systems programming.

Feature flags: Represent features as bits in an integer. Counting set bits tells you how many features are enabled.

Combinatorics: The number of set bits in a bitmask tells you the size of the subset it represents.

What New Concept Does This Teach?

You learn two approaches to examining bits: the shift-and-check loop (check the least significant bit, then shift right) and Brian Kernighan's trick (repeatedly clear the lowest set bit with n & (n - 1) until n is 0). Kernighan's trick runs in O(k) where k is the number of set bits, not the total bit width.

Two Approaches

Method 1: Shift and Check

Check the rightmost bit with n & 1. If it is 1, increment count. Then shift right with n >> 1. Repeat until n is 0.

Runs in O(b) where b is the number of bits (e.g., 32 for a 32-bit integer).

Method 2: Brian Kernighan's Trick

Use n = n & (n - 1) to clear the lowest set bit. Count how many times you do this before n becomes 0.

Runs in O(k) where k is the number of set bits — faster when few bits are set.

Time & Space Complexity

Time: O(b) for shift-and-check, O(k) for Kernighan's trick (k = number of set bits, b = total bits).

Space: O(1)

Pseudocode

Method 1: Shift and Check

function count_set_bits(n):
    count = 0
    while n > 0:
        if (n AND 1) == 1:
            count = count + 1
        n = n >> 1   // shift right by 1
    return count

Method 2: Kernighan's Trick

function count_set_bits(n):
    count = 0
    while n > 0:
        n = n AND (n - 1)   // clear lowest set bit
        count = count + 1
    return count

Common Pitfalls

1. Signed right shift

In some languages, >> on negative numbers fills with 1s (arithmetic shift), creating an infinite loop. Use unsigned shift (>>>) or handle negative numbers separately.

What You Learned

Key Takeaways

n & 1 extracts the least significant bit.

n >> 1 divides by 2 (shifts all bits right).

n & (n - 1) clears the lowest set bit.

Kernighan's trick is adaptive — faster for sparse bit patterns.
