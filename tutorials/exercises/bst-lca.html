BST: Lowest Common Ancestor

Trees (BST) Intermediate
Prerequisites
  • #122 BST: Search — navigating a BST by comparison

What You Will Learn

Find the Lowest Common Ancestor (LCA) of two nodes in a BST — the deepest node that is an ancestor of both. Think of it as two people walking up their family tree; the LCA is where their paths first meet.

In a BST, the key insight is simple: from the root, if both targets are left, go left. If both are right, go right. The moment they split (one left, one right, or one equals the current node), you have found the LCA!

The Algorithm

How It Works

1. Start at the root.

2. If both target values are less than the current node, go left (both are in the left subtree).

3. If both target values are greater than the current node, go right (both are in the right subtree).

4. Otherwise, the current node is the LCA! (The paths to the two targets diverge here.)

Time & Space Complexity

Time: O(h) — traverse at most the height of the tree.

Space: O(1) — iterative, no recursion needed.

Note: For a general binary tree (not BST), LCA requires O(n) time. The BST ordering makes this O(h)!

Pseudocode

function lowestCommonAncestor(root, p, q):
    node = root
    while node:
        if p < node.val and q < node.val:
            node = node.left     // both left
        else if p > node.val and q > node.val:
            node = node.right    // both right
        else:
            return node          // split! this is LCA

Walkthrough

LCA(1, 6) in BST [8, 3, 10, 1, 6, 14]

        8
       / \
      3   10
     / \    \
    1   6   14

At 8: both 1 and 6 < 8 → go left
At 3: 1 < 3 (left) but 6 > 3 (right) → SPLIT!
LCA = 3

Path to 1: 8 → 3 → 1
Path to 6: 8 → 3 → 6
They diverge at 3.

LCA(1, 14)

At 8: 1 < 8 (left) but 14 > 8 (right) → SPLIT!
LCA = 8 (the root)

The paths diverge immediately at the root.

Common Pitfalls

1. Forgetting that a node can be its own ancestor

If one target equals the current node, the split condition is satisfied. That node IS the LCA. For example, LCA(3, 6) = 3 because 3 is an ancestor of 6.

2. Using general tree LCA for a BST

The general LCA algorithm (check both subtrees, return non-null) works but is O(n). The BST version is O(h) because it uses the ordering property to avoid searching both subtrees.

What You Learned

Key Takeaways

LCA = where the paths split: in a BST, you can find this in O(h) by comparing both targets with the current node.

Three possible decisions: both left, both right, or split (including when one target equals the current node).

BST ordering makes this efficient: no need to explore both subtrees like in a general binary tree.
