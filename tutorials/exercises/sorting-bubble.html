Sorting: Bubble Sort

Sorting Beginner
Prerequisites
  • #26 reverse_in_place — swapping adjacent elements
  • #29 is_sorted — checking sorted order

Why Bubble Sort?

Use Cases

Education: The simplest sorting algorithm to understand and implement. It builds intuition for how sorting works.

Nearly-sorted data: With an early-exit optimization, bubble sort runs in O(n) on already-sorted or nearly-sorted arrays.

Small datasets: For tiny arrays (5-10 elements), the overhead of fancier algorithms is not worth it.

Detecting sortedness: If no swaps happen in a pass, the array is sorted — a free check built into the algorithm.

What New Concept Does This Teach?

This is your first sorting algorithm. It teaches you the idea of repeated passes with adjacent swaps: compare two neighbors, swap if they are out of order, repeat until everything is sorted. It also gives you a visceral understanding of O(n²) time complexity — you can see the nested loops in action.

How It Works

The Algorithm

Walk through the array from left to right, comparing each pair of adjacent elements. If the left element is larger than the right, swap them. After one full pass, the largest element has "bubbled up" to the end. Repeat for the remaining unsorted portion.

Each pass guarantees one more element is in its final position. After at most n-1 passes, the entire array is sorted.

Time & Space Complexity

Time: O(n²) worst and average case. Two nested loops, each up to n.

Time: O(n) best case (already sorted, with early-exit optimization).

Space: O(1) — sorts in place, only needs a temporary variable for swaps.

Speed

Pseudocode

function bubble_sort(arr):
    n = length(arr)
    for pass from 0 to n - 2:
        swapped = false
        for i from 0 to n - 2 - pass:
            if arr[i] > arr[i + 1]:
                swap(arr[i], arr[i + 1])
                swapped = true
        if not swapped:
            break    // array is already sorted

Walkthrough

Let's trace sorting [64, 34, 25, 12, 22, 11, 90]:

Pass 1

Compare 64,34 → swap  → [34,64,25,12,22,11,90]
Compare 64,25 → swap  → [34,25,64,12,22,11,90]
Compare 64,12 → swap  → [34,25,12,64,22,11,90]
Compare 64,22 → swap  → [34,25,12,22,64,11,90]
Compare 64,11 → swap  → [34,25,12,22,11,64,90]
Compare 64,90 → no swap
90 is now in its final position.

Remaining passes continue until sorted

Each pass places one more element at the end. After at most 6 passes, the 7-element array is fully sorted.

Common Pitfalls

1. Forgetting the early-exit

Without the swapped flag, bubble sort always does n-1 passes even on sorted arrays. The early-exit check turns O(n²) best case into O(n).

2. Wrong inner loop bound

The inner loop should go up to n - 2 - pass, not n - 1. After each pass, the last pass elements are already sorted.

What You Learned

Key Takeaways

Adjacent swaps are the simplest way to move elements toward sorted order.

O(n²) comes from nested iteration — you can visually see why it is slow on large arrays.

Stability: Bubble sort is stable — equal elements keep their original relative order.

In-place: No extra array needed, just a temp variable for swapping.
