Longest Substring with at Most K Distinct Characters

Sliding Window Intermediate
Required Learning
  • #84 Sliding Window: max_sum_subarray_k — the sliding window pattern
  • #51 Maps: increment_count — tracking frequencies

The Problem

Definition

Given a string and an integer K, find the length of the longest substring that contains at most K distinct characters.

Input:  s = "eceba", k = 2
Output: 3  (substring "ece" has 2 distinct chars)

Real-World: DNA Sequence Analysis

In bioinformatics, you might want to find the longest segment of DNA that uses only K different nucleotides. Or in log analysis, the longest period where errors came from at most K different services.

The Approach: Variable-Size Sliding Window

Expand and Shrink

Unlike fixed-size windows (#84), this window grows and shrinks:

  1. Expand: Move right to include the next character. Add it to a frequency map.
  2. Shrink: If the map has more than K distinct keys, move left forward, removing characters until we're back to ≤ K distinct.
  3. Track best: After each expansion (when valid), update the maximum length.
def longest_k_distinct(s, k):
    counts = {}
    left = 0
    best = 0

    for right in range(len(s)):
        # Expand: add s[right]
        counts[s[right]] = counts.get(s[right], 0) + 1

        # Shrink: too many distinct chars
        while len(counts) > k:
            counts[s[left]] -= 1
            if counts[s[left]] == 0:
                del counts[s[left]]
            left += 1

        best = max(best, right - left + 1)

    return best

Complexity

Time: O(n) — each character enters and exits the window at most once.

Space: O(K) — the frequency map has at most K+1 entries.

Walkthrough

s = "eceba", k = 2

Step by Step

right=0: window="e"     counts={e:1}       len=1 ≤ 2 → best=1
right=1: window="ec"    counts={e:1,c:1}   len=2 ≤ 2 → best=2
right=2: window="ece"   counts={e:2,c:1}   len=2 ≤ 2 → best=3
right=3: window="eceb"  counts={e:2,c:1,b:1} len=3 > 2!
  shrink: remove 'e'    counts={e:1,c:1,b:1} still 3
  shrink: remove 'c'    counts={e:1,b:1}   len=2 ≤ 2
  window="eb" → best still 3
right=4: window="eba"   counts={e:1,b:1,a:1} len=3 > 2!
  shrink: remove 'e'    counts={b:1,a:1}   len=2 ≤ 2
  window="ba" → best still 3

Answer: 3

Common Pitfalls

1. Not deleting zero-count entries

When a character's count drops to 0, delete it from the map. Otherwise len(counts) won't reflect the actual number of distinct characters.

2. Edge case: k = 0

If k = 0, no characters are allowed — return 0 immediately.
