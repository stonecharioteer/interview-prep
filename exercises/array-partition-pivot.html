Arrays: Partition by Pivot

Arrays Intermediate
Required Learning
  • #26 reverse_in_place — swapping elements

The Problem

Definition

Rearrange an array so that all elements less than a chosen pivot come before it, and all elements greater than or equal to the pivot come after. The pivot ends up at its final sorted position.

This is the core building block of quicksort.

Real-World Analogy: Sorting Mail

Imagine a mail carrier with a stack of letters. They pick a "divider" zip code and split letters into two piles: everything below the divider goes left, everything above goes right. They don't fully sort either pile — they just partition. This is exactly what the pivot does.

Lomuto Partition (Simpler)

How It Works

Choose the last element as pivot. Maintain a boundary i that tracks where small elements end. Scan left to right; whenever you find an element < pivot, swap it to position i and advance i. Finally, swap the pivot to position i.

def lomuto_partition(arr, lo, hi):
    pivot = arr[hi]
    i = lo                    # boundary for "small" elements

    for j in range(lo, hi):
        if arr[j] < pivot:
            swap(arr[i], arr[j])
            i += 1

    swap(arr[i], arr[hi])     # place pivot in its final position
    return i                  # pivot index

Walkthrough

Partition [8, 3, 1, 7, 0, 10, 2] with pivot = 2 (last element):

Scan and Swap

j=0: 8 ≥ 2 → skip         [8, 3, 1, 7, 0, 10, 2]  i=0
j=1: 3 ≥ 2 → skip         [8, 3, 1, 7, 0, 10, 2]  i=0
j=2: 1 < 2 → swap(0,2)    [1, 3, 8, 7, 0, 10, 2]  i=1
j=3: 7 ≥ 2 → skip         [1, 3, 8, 7, 0, 10, 2]  i=1
j=4: 0 < 2 → swap(1,4)    [1, 0, 8, 7, 3, 10, 2]  i=2
j=5: 10 ≥ 2 → skip        [1, 0, 8, 7, 3, 10, 2]  i=2
Final: swap pivot to i=2   [1, 0, 2, 7, 3, 10, 8]
                             ←less→  P  ←greater→

Complexity

Time: O(n) — single pass through the array.

Space: O(1) — in-place swaps.

Common Pitfalls

1. Not handling equal elements

Decide whether equals go left or right and be consistent. Lomuto puts equals on the right.

2. Bad pivot choice

If the pivot is always the smallest or largest, partition produces one empty side — leading to O(n²) quicksort. Median-of-three or random pivot selection helps.
