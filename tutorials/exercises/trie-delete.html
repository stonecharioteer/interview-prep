Trie: Delete Word

Trie Advanced
Required Learning
  • #92 Trie: search — finding words in a trie
  • #82 Trie: insert — building a trie

The Problem

Definition

Delete a word from a trie without breaking other words that share the same prefix. Only remove nodes that are no longer needed by any other word.

Mental Model: Pruning a Shared Path

Imagine a highway system where multiple destinations share road segments. Removing one destination means you can only tear up the road segments that are exclusive to that destination. Shared segments must stay for other routes.

Deleting "card" from a trie containing "car", "card", "care": you can only remove the 'd' node because 'c', 'a', 'r' are shared with "car" and "care".

How It Works

The Algorithm (Recursive)

Step 1: Walk down to the end of the word (like search).

Step 2: Unmark is_end on the last node.

Step 3: Walk back up. At each node, ask: "Does this node have any children? Is it the end of another word?" If neither, it's safe to remove.

Step 4: Stop removing when you hit a node that IS needed (has children or is_end).

def delete(node, word, depth=0):
    if depth == len(word):
        node.is_end = False          # unmark
        return len(node.children) == 0  # delete if no children

    char = word[depth]
    child = node.children[char]
    should_delete = delete(child, word, depth + 1)

    if should_delete:
        del node.children[char]       # prune the child
        # delete this node too if it has no other children and isn't an end
        return not node.is_end and len(node.children) == 0

    return False

Complexity

Time: O(m) where m = length of the word.

Space: O(m) for the recursion stack.

Walkthrough

Delete "card" from trie containing: car, card, care

Phase 1: Walk down to "card"

root → c → a → r → d
Found the word. Unmark 'd' as end-of-word.

Phase 2: Walk back up and prune

Node 'd': no children, not end-of-word → REMOVE (it's exclusive to "card")
Node 'r': still has children ('e' for "care"), is_end for "car" → KEEP
Node 'a': still has child 'r' → KEEP
Node 'c': still has child 'a' → KEEP

Only the 'd' node was removed. "car" and "care" are untouched.

Common Pitfalls

1. Deleting too many nodes

If you remove nodes without checking for other children or word endings, you'll break words that share the same prefix. Always check both conditions before removing.

2. Forgetting to unmark is_end

Even if no nodes can be removed (e.g., deleting "car" when "card" exists), you must still unmark is_end on the 'r' node. Otherwise "car" will still appear in searches.

3. Deleting a word that doesn't exist

Always verify the word exists before attempting deletion. If you reach a dead end during traversal, or the final node isn't marked as end-of-word, do nothing.
