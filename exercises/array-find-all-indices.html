Arrays: Find All Indices

Arrays Beginner
Prerequisites
  • #20 find_index — returning position vs value

What's New Here

find_index returns a single index and stops. This exercise teaches you to collect multiple results into a new array. You build a result array incrementally as you scan. This "collect" pattern is the foundation for filtering, mapping, and many functional programming idioms.

Why Find All Indices?

Real-World Use Cases

Text search: Find all positions of a word in a document for highlighting.

Data filtering: Get all rows matching a condition for further processing.

Pattern matching: Find all positions where a pattern occurs in a sequence.

Batch operations: Collect all indices to update or delete in one pass.

The Algorithm

How It Works

Create an empty result array. Scan through the input array: whenever an element matches the target, append the current index to the result. Return the result array at the end. No early termination — scan everything.

Time & Space Complexity

Time: O(n) — must check every element.

Space: O(k) where k is the number of matches (worst case O(n) if every element matches).

Walkthrough

Find all indices of 3 in [5, 3, 8, 3, 1, 3, 7]:

Step by step

Initialize: result = []

Index 0: 5 == 3? No.  result = []
Index 1: 3 == 3? Yes! result = [1]
Index 2: 8 == 3? No.  result = [1]
Index 3: 3 == 3? Yes! result = [1, 3]
Index 4: 1 == 3? No.  result = [1, 3]
Index 5: 3 == 3? Yes! result = [1, 3, 5]
Index 6: 7 == 3? No.  result = [1, 3, 5]

Return [1, 3, 5].

Pseudocode

function find_all_indices(arr, target):
    result = []
    for i from 0 to len(arr) - 1:
        if arr[i] == target:
            result.append(i)
    return result

Common Pitfalls

1. Appending values instead of indices

Append i (the index), not arr[i] (the value). The value is always the target — that's not useful.

2. Forgetting to handle zero matches

If the target isn't found, return an empty array [], not -1 or null. The caller can check len(result) == 0.

What You Learned

Key Takeaways

Building a result array — start empty, append as you go.

O(k) extra space — the output size depends on the data, not just the input size.

This "collect matches" pattern is the basis of filter operations.
