Trie: Longest Common Prefix

Trie Intermediate

The Problem

Definition

Find the longest common prefix (LCP) among all words stored in a trie. The LCP is the longest string that is a prefix of every word in the trie.

Mental Model: Highway Before the Fork

Imagine all words as destinations on a highway. They all start at the same entrance (the root). The longest common prefix is the stretch of highway before the road forks. Once the road splits into two or more lanes, that's where the common prefix ends.

For "flower", "flow", "flight": the highway goes f → l, then forks into 'o' and 'i'. The LCP is "fl" — the road before the fork.

How It Works

Walk Until You Fork (or End)

Starting from the root, walk down the trie. At each node, check:

  1. Does this node have exactly one child? If yes, that character is part of the LCP. Continue.
  2. Does this node have multiple children? STOP. The road forks here.
  3. Is this node marked as is_end? STOP. One word ends here, so the prefix can't be longer.
  4. Does this node have zero children? STOP. Dead end (only possible if trie has exactly one word).
def longest_common_prefix():
    lcp = ""
    node = root
    while True:
        # Stop if node has != 1 child or is end of a word
        if len(node.children) != 1 or node.is_end:
            break
        char = next(iter(node.children))  # the single child key
        lcp += char
        node = node.children[char]
    return lcp

Complexity

Time: O(L) where L = length of the LCP. In the worst case (all words are identical), L = word length.

Space: O(L) for storing the LCP string.

Walkthrough

Example: "flower", "flow", "flight"

root: 1 child ('f') → LCP = "f"
  'f': 1 child ('l') → LCP = "fl"
  'l': 2 children ('o', 'i') → STOP! Road forks.

LCP = "fl"

Example: "dog", "racecar", "car"

root: 3 children ('d', 'r', 'c') → STOP immediately!

LCP = "" (empty string — no common prefix)

Common Pitfalls

1. Forgetting the is_end check

If the trie contains "app" and "apple", at the second 'p' node is_end=true. The LCP is "app", not "appl". The is_end check prevents extending past a shorter word.

2. Empty trie

If the trie is empty (root has no children), the LCP is the empty string. Handle this edge case.

3. Single word in trie

If only one word exists, the LCP is that entire word. The algorithm naturally handles this since every node has exactly one child until the end.
