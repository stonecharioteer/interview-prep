EXERCISE #134

Heap: Merge Two Heaps

Heap Intermediate
Prerequisites
  • #81 Heapify — build a heap from an array using bottom-up sift-down

What You Will Learn

Given two valid min-heaps, merge them into a single valid min-heap. The approach: concatenate both arrays, then heapify.

Mental model: dump both piles of sorted mail onto one desk, then reorganize from the bottom up. The bottom-up heapify fixes everything in O(n) time.

The Algorithm

How It Works

1. Concatenate the two heap arrays into one array.

2. Run bottom-up heapify on the combined array:

   a. Start from the last non-leaf: index floor(n/2) - 1

   b. For each node, sift it down to its correct position.

   c. Work backwards to index 0.

3. The result is a valid min-heap containing all elements from both heaps.

Time & Space Complexity

Time: O(n + m) — concatenation is O(n+m), heapify is O(n+m). Total: linear.

Space: O(n + m) — for the merged array.

Speed

Pseudocode

function mergeHeaps(heapA, heapB):
    merged = heapA + heapB          // concatenate
    n = len(merged)
    for i in range(n // 2 - 1, -1, -1):
        siftDown(merged, i, n)
    return merged

function siftDown(arr, i, n):
    while True:
        left = 2 * i + 1
        right = 2 * i + 2
        smallest = i
        if left < n and arr[left] < arr[smallest]:
            smallest = left
        if right < n and arr[right] < arr[smallest]:
            smallest = right
        if smallest == i:
            break
        swap(arr[i], arr[smallest])
        i = smallest

Walkthrough

Merge [2, 5, 8, 10] and [3, 7, 12, 15]

Step 1: Concatenate → [2, 5, 8, 10, 3, 7, 12, 15]

Step 2: Heapify (start at index 3, the last non-leaf)
  Index 3 (val 10): children = 3 (idx 7 is 15 only). 10 < 15 → no swap.
  Index 2 (val 8):  children = 7 (idx 5), 12 (idx 6). 7 < 8 → swap 8 and 7.
    Array: [2, 5, 7, 10, 3, 8, 12, 15]
  Index 1 (val 5):  children = 10 (idx 3), 3 (idx 4). 3 < 5 → swap 5 and 3.
    Array: [2, 3, 7, 10, 5, 8, 12, 15]
  Index 0 (val 2):  children = 3, 7. 2 < both → no swap.

Result: [2, 3, 7, 10, 5, 8, 12, 15] — valid min-heap!

Common Pitfalls

1. Inserting one-by-one instead of heapifying

Inserting each element from heap B into heap A one at a time is O(m log(n+m)). Concatenation + heapify is O(n + m). For large heaps, heapify is much faster.

2. Assuming the concatenation is already a valid heap

Even though both inputs are valid heaps, their concatenation is NOT a valid heap. You must run heapify on the merged array.

3. Using sift-up instead of sift-down

Bottom-up heapify requires sift-down. Using sift-up would give O(n log n) instead of O(n).

What You Learned

Key Takeaways

Merge = concatenate + heapify: The simplest and most efficient approach.

O(n + m) is optimal: You must read every element at least once, so linear is the best possible.

Heapify does the heavy lifting: The same bottom-up sift-down from Exercise #81.
