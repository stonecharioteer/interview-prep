Arrays: Finding the Maximum

Arrays Beginner
Prerequisites

What's New Here

You already know the linear scan from finding the minimum. This exercise reinforces the same pattern but with the opposite comparison: instead of <, you use >. Recognizing that the same skeleton solves both problems is the real lesson — algorithms are reusable templates.

Why Find the Maximum?

Real-World Use Cases

Leaderboards: Finding the top scorer in a game.

Peak detection: Identifying the highest sensor reading (temperature spike, max load).

Resource planning: Finding the maximum memory usage across time intervals.

Finance: Finding the highest stock price in a trading period.

The Algorithm

How It Works

Start by assuming the first element is the maximum. Walk through every remaining element: if it is greater than your current maximum, update. When done, you have the answer.

The only difference from min: flip the comparison operator.

Time & Space Complexity

Time: O(n) — every element must be checked.

Space: O(1) — one variable tracks the current maximum.

Walkthrough

Let's trace finding the maximum of [12, 45, 7, 89, 23, 56]:

Step by step

Index 0: value=12. First element, so max=12.
Index 1: value=45. 45 > 12? Yes! New max=45.
Index 2: value=7.  7 > 45?  No, skip.
Index 3: value=89. 89 > 45? Yes! New max=89.
Index 4: value=23. 23 > 89? No, skip.
Index 5: value=56. 56 > 89? No, skip.

Result: maximum is 89 at index 3.

Pseudocode

function max(arr):
    if arr is empty:
        error "empty array"
    current_max = arr[0]
    for i from 1 to len(arr) - 1:
        if arr[i] > current_max:
            current_max = arr[i]
    return current_max

Common Pitfalls

1. Empty array

Always guard against empty input. There is no maximum of nothing.

2. All negative values

If you initialize max = 0, you'll get the wrong answer when all values are negative (e.g., [-5, -3, -8] should return -3, not 0). Always start with arr[0].

3. Confusing min and max

The only difference is the comparison operator. Double-check you're using > for max and < for min.

What You Learned

Key Takeaways

Algorithm templates are reusable — changing one operator transforms min into max.

Initialization matters — always use arr[0], not an arbitrary constant.

The scan pattern works for any "find the extreme" problem.
