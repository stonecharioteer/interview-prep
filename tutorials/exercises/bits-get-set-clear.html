Why Get/Set/Clear Bit?

Use Cases

Feature flags: Store booleans efficiently — one integer can hold 32 or 64 flags.

Permissions: Unix file permissions use bit fields (read = 4, write = 2, execute = 1).

Networking: IP subnet masks are manipulated bit by bit.

Embedded systems: Hardware registers are controlled by setting/clearing individual bits.

What New Concept Does This Teach?

You learn to create bit masks using 1 << i to isolate a specific bit position. Combined with AND, OR, and AND-NOT, you can read, set, or clear any individual bit without affecting the others.

Three Operations

Get Bit (read bit i)

Create a mask 1 << i and AND it with n: (n >> i) & 1. Result is 0 or 1.

Set Bit (turn bit i on)

OR the number with the mask: n | (1 << i). This forces bit i to 1 without touching other bits.

Clear Bit (turn bit i off)

AND with the inverted mask: n & ~(1 << i). This forces bit i to 0 without touching other bits.

Time & Space Complexity

Time: O(1) — each operation is a constant number of bitwise instructions.

Space: O(1)

Pseudocode

Get Bit

function get_bit(n, i):
    return (n >> i) AND 1

Set Bit

function set_bit(n, i):
    mask = 1 << i
    return n OR mask

Clear Bit

function clear_bit(n, i):
    mask = NOT (1 << i)
    return n AND mask

Common Pitfalls

1. Off-by-one on bit index

Bit 0 is the least significant (rightmost) bit. Bit 7 in an 8-bit number is the leftmost. Do not confuse positional index with display order.

2. Forgetting the NOT for clear

A common mistake is writing n & (1 << i) to clear a bit. That actually isolates the bit. You need the inverted mask: n & ~(1 << i).

What You Learned

Key Takeaways

1 << i creates a mask with only bit i set.

OR sets a bit, AND with NOT clears a bit, shift-and-AND reads a bit.

These three operations are the building blocks for all bit manipulation problems.
