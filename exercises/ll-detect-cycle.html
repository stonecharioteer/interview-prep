Linked List: Detect Cycle

Linked Lists Intermediate

What You Will Learn

How to detect whether a linked list contains a cycle using Floyd's Tortoise and Hare algorithm. The tortoise moves one step at a time; the hare moves two steps. If they meet, there is a cycle. This runs in O(n) time with O(1) space.

The Problem

Definition

Given the head of a linked list, determine if the list has a cycle. A cycle exists if some node's next pointer points back to a previously visited node, causing infinite traversal.

Why Floyd's Algorithm?

Key Insight

If there is a cycle, the fast pointer (hare) will eventually "lap" the slow pointer (tortoise) inside the cycle. Think of two runners on a circular track — the faster one always catches the slower one.

Time & Space Complexity

Time: O(n) — the hare enters the cycle and catches the tortoise within at most one full loop.

Space: O(1) — only two pointers, no hash set needed.

Pseudocode

function detect_cycle(head):
    tortoise = head
    hare = head

    while hare is not null and hare.next is not null:
        tortoise = tortoise.next         // 1 step
        hare = hare.next.next            // 2 steps

        if tortoise == hare:
            return true   // cycle detected!

    return false          // hare reached end, no cycle

Walkthrough

Tracing 1 → 2 → 3 → 4 → 2 (cycle)

Start: T=1, H=1
Step 1: T=2, H=3
Step 2: T=3, H=2 (hare wrapped around cycle)
Step 3: T=4, H=4. T == H! Cycle detected!

Tracing 1 → 2 → 3 (no cycle)

Start: T=1, H=1
Step 1: T=2, H=3
Step 2: H.next is null. No cycle.

Common Pitfalls

1. Null checks on hare

Always check both hare != null AND hare.next != null before moving. The hare jumps two steps and can skip past the end.

2. Comparing values instead of references

Two different nodes can have the same value. You must compare node references (identity), not values.

What You Learned

Key Takeaways

Floyd's algorithm: Two pointers at different speeds detect cycles in O(n) time, O(1) space.

Extends to: Finding the cycle start node and cycle length (by continuing from the meeting point).
