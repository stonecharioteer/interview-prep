Trie: Count Words With Prefix

Trie Intermediate
Required Learning
  • #107 Trie: starts_with — prefix search
  • #82 Trie: insert — building a trie

The Problem

Definition

Given a trie containing several words and a prefix string, count how many stored words start with that prefix.

Mental Model: The Neighborhood

Think of the trie as a city map. Each prefix is a neighborhood (a subtree). Walking to the prefix node is like driving to that neighborhood. Once there, you count all the houses (word endings marked with a star) in that neighborhood by exploring every street (DFS through the subtree).

If the neighborhood doesn't exist (prefix not in trie), the count is zero — you can't even get there.

How It Works

Two-Phase Algorithm

Phase 1 — Navigate to the prefix node: Walk the trie character by character, just like starts_with. If any character is missing, return 0.

Phase 2 — Count word endings in subtree: From the prefix node, run a DFS/BFS. Every time you encounter a node with is_end = true, increment the count.

def count_words_with_prefix(prefix):
    # Phase 1: navigate to the prefix node
    node = root
    for char in prefix:
        if char not in node.children:
            return 0
        node = node.children[char]

    # Phase 2: DFS to count all word endings
    count = 0
    stack = [node]
    while stack:
        curr = stack.pop()
        if curr.is_end:
            count += 1
        for child in curr.children.values():
            stack.append(child)
    return count

Complexity

Time: O(p + n) where p = prefix length, n = number of nodes in the subtree.

Space: O(n) for the DFS stack in the worst case.

Phase 2: Count word endings in subtree

Node 'r' → is_end=true  → count=1  ("car")
  Child 'd' → is_end=true  → count=2  ("card")
  Child 'e' → is_end=true  → count=3  ("care")

Result: 4 words start with "car"

Common Pitfalls

1. Forgetting the prefix node itself

If the prefix itself is a complete word (e.g., "car" is a word), its own is_end flag must be counted too. Don't start counting only from the children.

2. Returning 0 vs. returning "prefix not found"

Both "prefix not in trie" and "prefix exists but no words end there" return 0. Make sure you handle the Phase 1 failure early.
