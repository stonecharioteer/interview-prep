Why Merge Two Sorted Linked Lists?

Use Cases

Merge sort on linked lists: The merge step of merge sort on linked lists uses this exact operation.

K-way merge: Merging K sorted lists (used in external sorting and merge-K-sorted-streams) repeatedly merges pairs.

Classic interview question: One of the most commonly asked linked list problems. Tests pointer manipulation under pressure.

What New Concept Does This Teach?

This exercise teaches the dummy head technique: create a temporary node at the start of the result list so you never have to special-case "is the result list empty?" You build the result by advancing a tail pointer. At the end, return dummy.next. This pattern eliminates a whole class of null-pointer bugs.

How It Works

The Algorithm

Create a dummy node and a tail pointer to it.

While both lists are non-empty: compare heads, link the smaller one to tail.next, advance that list's pointer and tail.

Attach remainder: when one list is exhausted, link the other list's remaining nodes directly.

Return dummy.next.

Time & Space Complexity

Time: O(n + m) — each node from both lists is visited exactly once.

Space: O(1) — we reuse existing nodes, only creating the dummy node.

Pseudocode

function merge_sorted(head_a, head_b):
    dummy = new Node(0)      // dummy head
    tail = dummy

    while head_a is not null and head_b is not null:
        if head_a.val <= head_b.val:
            tail.next = head_a
            head_a = head_a.next
        else:
            tail.next = head_b
            head_b = head_b.next
        tail = tail.next

    // Attach whichever list has remaining nodes
    if head_a is not null:
        tail.next = head_a
    else:
        tail.next = head_b

    return dummy.next

Common Pitfalls

1. Forgetting the dummy node

Without a dummy head, you need an if-else for the first node. The dummy pattern eliminates this edge case entirely.

2. Not attaching the remaining list

When one list is exhausted, the other still has nodes. You must link them — do not just stop.

What You Learned

Key Takeaways

Dummy head simplifies linked list construction by removing null-check edge cases.

Two-pointer merge is the same pattern as merging sorted arrays, but with pointer manipulation instead of index arithmetic.

O(1) space — no new nodes are created, just re-linking existing ones.
