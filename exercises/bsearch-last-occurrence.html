Binary Search: Find Last Occurrence

Binary Search Intermediate
Prerequisites
  • #38 first_occurrence — searching left after finding target

Why Find Last Occurrence?

Use Cases

Range end: Combined with first occurrence, gives you the complete range [first, last] of a value in sorted data.

Counting occurrences: count = last_occurrence - first_occurrence + 1 in O(log n).

Upper bound: Standard library functions like upper_bound / bisect_right are closely related (upper_bound returns last + 1).

What New Concept Does This Teach?

This is the mirror of first occurrence. When you find the target, save the position and keep searching right (set lo = mid + 1). Together, first and last occurrence teach you that binary search is really about finding boundaries — the transition points in sorted data.

How It Works

The Algorithm

Same as binary search, but when arr[mid] == target:

Save mid as a candidate result, then set lo = mid + 1 to keep searching the right half for a later occurrence.

Time & Space Complexity

Time: O(log n)

Space: O(1)

Speed

Pseudocode

function last_occurrence(arr, target):
    lo = 0
    hi = length(arr) - 1
    result = -1

    while lo <= hi:
        mid = (lo + hi) / 2
        if arr[mid] == target:
            result = mid          // save candidate
            lo = mid + 1          // keep searching RIGHT
        else if arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1

    return result

Walkthrough

Find last occurrence of 3 in [1, 2, 3, 3, 3, 4, 5]:

Step by step

lo=0, hi=6, mid=3: arr[3]=3 == target! Save result=3. Set lo=4.
lo=4, hi=6, mid=5: arr[5]=4 > 3. Set hi=4.
lo=4, hi=4, mid=4: arr[4]=3 == target! Save result=4. Set lo=5.
lo=5, hi=4: loop ends.
Result: last occurrence at index 4.

Combining First and Last

Counting Occurrences in O(log n)

first = first_occurrence(arr, target)   // index 2
last  = last_occurrence(arr, target)    // index 4
count = last - first + 1               // 3 occurrences

This is much faster than scanning the full array (O(n)) when data is sorted.

What You Learned

Key Takeaways

First + Last = Range: Two binary searches give you the complete range of a value.

Symmetry: First occurrence searches left on match; last occurrence searches right. Same structure, one line different.

Boundary thinking: Binary search finds where sorted data transitions from one condition to another.
