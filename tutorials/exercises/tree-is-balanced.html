Trees: Is Balanced?

Trees (Binary) Intermediate
Prerequisites
  • #89 Tree Height — computing height of a binary tree

What You Will Learn

A binary tree is height-balanced if for every node, the heights of its left and right subtrees differ by at most 1. Watch heights bubble up from leaves. Each node acts like a seesaw — if the height difference exceeds 1, it tilts and the tree is unbalanced.

The Algorithm

How It Works (Efficient O(n) approach)

1. Recursively compute the height of each subtree bottom-up.

2. At each node, check if |leftHeight - rightHeight| ≤ 1.

3. If any node is imbalanced, propagate -1 upward (early termination signal).

4. If the root receives a non-negative value, the tree is balanced.

Mental model: each node is a seesaw. Heights are weights on each side. If the difference exceeds 1, the seesaw tips over.

Time & Space Complexity

Time: O(n) — visit each node once (bottom-up approach).

Space: O(h) — recursion stack depth.

Pseudocode

function isBalanced(root):
    return checkHeight(root) != -1

function checkHeight(node):
    if node is null:
        return 0
    leftH = checkHeight(node.left)
    if leftH == -1: return -1
    rightH = checkHeight(node.right)
    if rightH == -1: return -1
    if |leftH - rightH| > 1:
        return -1
    return max(leftH, rightH) + 1

Common Pitfalls

1. Checking only the root

A tree can have balanced root heights but an imbalanced subtree deeper down. You must check every node.

2. O(n^2) naive approach

Calling height() at every node independently is O(n^2). The bottom-up approach computes height and checks balance in one pass: O(n).

3. Off-by-one in height

Null nodes have height 0, leaves have height 1. Be consistent with your convention or the difference check breaks.

What You Learned

Key Takeaways

Bottom-up is key: Computing heights bottom-up and checking balance simultaneously gives O(n) time.

The seesaw mental model: Each node is a seesaw. If the height difference exceeds 1, it tips. One tipped seesaw means the whole tree is unbalanced.

-1 as a signal: Using -1 to propagate imbalance upward avoids separate boolean tracking.
