Arrays: Average

Arrays Beginner

What's New Here

You already know how to compute a sum. The average combines two quantities: the sum and the count. This is your first example of composing simple operations into a more complex result. The key insight: the division happens after the loop, not inside it.

Why Compute an Average?

Real-World Use Cases

Statistics: Mean is the most common measure of central tendency.

Grading: Average test score to assign a final grade.

Performance metrics: Average response time, average throughput.

Signal processing: Moving averages to smooth noisy data.

The Algorithm

How It Works

Compute the sum of all elements (accumulator pattern from #3), then divide by the number of elements. That's it — average = sum / count.

Time & Space Complexity

Time: O(n) — one pass to compute the sum.

Space: O(1) — just a sum variable and the count.

Walkthrough

Let's compute the average of [85, 92, 78, 90, 88]:

Step by step

Initialize: sum = 0, count = 5

Index 0: sum = 0 + 85  = 85
Index 1: sum = 85 + 92 = 177
Index 2: sum = 177 + 78 = 255
Index 3: sum = 255 + 90 = 345
Index 4: sum = 345 + 88 = 433

Average = 433 / 5 = 86.6

Pseudocode

function average(arr):
    if arr is empty:
        error "empty array"
    total = 0
    for i from 0 to len(arr) - 1:
        total = total + arr[i]
    return total / len(arr)

Common Pitfalls

1. Division by zero

Always check for an empty array before dividing.

2. Integer division

In many languages, dividing two integers truncates the result (e.g., 7 / 2 = 3 instead of 3.5). Make sure at least one operand is a floating-point number.

3. Dividing inside the loop

Don't compute a "running average" by dividing at each step — that gives the wrong result. Sum first, divide once at the end.

What You Learned

Key Takeaways

Composing operations — average = sum / count, built from two simpler pieces.

Post-loop computation — some results require a final step after the loop ends.

Watch out for integer division and empty arrays.
