Maps: Invert Mapping

Maps (dict) Beginner
Required Learning
  • #42 Maps: get_or_default — dictionary basics
  • #51 Maps: increment_count — iterating over dicts

The Problem

Definition

Given a dictionary, swap all keys and values. The result maps each original value back to its key.

Input:  {"a": 1, "b": 2, "c": 3}
Output: {1: "a", 2: "b", 3: "c"}

The Duplicate Values Trap

What if two keys share the same value?

Input:  {"a": 1, "b": 1, "c": 2}
Simple: {1: "b", 2: "c"}     ← lost "a"!
Better: {1: ["a", "b"], 2: ["c"]}

You must decide: last-wins (simple) or collect all (list values). The problem statement will tell you which. When in doubt, collecting all is safer.

Real-World Analogy

Phone Book Reversal

A phone book maps name → phone number. Inverting it gives you a reverse lookup: phone number → name. This is exactly what caller ID does. If two people share a phone number, the reverse lookup needs to list both names.

The Algorithm

Simple Inversion (last-wins)

def invert(d):
    result = {}
    for key, value in d.items():
        result[value] = key
    return result

Safe Inversion (collect duplicates)

def invert_safe(d):
    result = {}
    for key, value in d.items():
        if value not in result:
            result[value] = []
        result[value].append(key)
    return result

Complexity

Time: O(n) — one pass through all key-value pairs.

Space: O(n) — the inverted dictionary has at most n entries.

Walkthrough

Example: Grade Mapping

Input: {"Alice": "A", "Bob": "B", "Carol": "A", "Dan": "C"}

Invert (safe):
  "Alice" → "A"  →  result = {"A": ["Alice"]}
  "Bob"   → "B"  →  result = {"A": ["Alice"], "B": ["Bob"]}
  "Carol" → "A"  →  result = {"A": ["Alice", "Carol"], "B": ["Bob"]}
  "Dan"   → "C"  →  result = {"A": ["Alice", "Carol"], "B": ["Bob"], "C": ["Dan"]}

Common Pitfalls

1. Values must be hashable

If the original values are lists or dicts, they can't be dictionary keys. You'd need to convert them to tuples or strings first.

2. Silently losing data

The simple version overwrites duplicate values without warning. Always ask: can values be duplicated? If yes, use the safe version.
