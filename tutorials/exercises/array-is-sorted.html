Arrays: Check if Sorted

Arrays Beginner
Prerequisites

What's New Here

Previous exercises examined one element at a time. This exercise introduces the pairwise comparison pattern: comparing each element with its neighbor. Instead of asking "what is arr[i]?", you ask "is arr[i] ≤ arr[i+1]?". This adjacent-element comparison is used in sorting algorithms, monotonicity checks, and detecting inversions.

Why Check if Sorted?

Real-World Use Cases

Precondition validation: Binary search requires sorted input — verify first.

Merge optimization: If data is already sorted, skip the sort step.

Debugging: Verify that a sorting algorithm produced correct output.

Data quality: Check if timestamps are in chronological order.

The Algorithm

How It Works

Compare each consecutive pair: arr[i] and arr[i+1]. If any pair is out of order (i.e., arr[i] > arr[i+1] for ascending), return false immediately. If all pairs pass, return true.

This combines two patterns: pairwise comparison and early termination.

Time & Space Complexity

Time: O(n) worst case (array is sorted), O(1) best case (first pair is out of order).

Space: O(1) — no extra storage.

Walkthrough

Sorted example: [2, 5, 8, 12, 16]

Pair (0,1): 2 ≤ 5? Yes, continue.
Pair (1,2): 5 ≤ 8? Yes, continue.
Pair (2,3): 8 ≤ 12? Yes, continue.
Pair (3,4): 12 ≤ 16? Yes, continue.
All pairs passed. Return true.

Unsorted example: [3, 7, 2, 9, 5]

Pair (0,1): 3 ≤ 7? Yes, continue.
Pair (1,2): 7 ≤ 2? No! Return false immediately.
(Pairs (2,3) and (3,4) are never checked.)

Pseudocode

function is_sorted(arr):
    for i from 0 to len(arr) - 2:
        if arr[i] > arr[i + 1]:
            return false
    return true

Common Pitfalls

1. Loop bound: len - 2, not len - 1

You compare arr[i] with arr[i+1], so the loop must stop one element before the end. Going to len - 1 would access arr[len], which is out of bounds.

2. Strict vs. non-strict ordering

Decide whether equal adjacent elements count as "sorted." Usually yes: [3, 3, 5] is sorted (non-decreasing). Use > to allow equals, ≥ to require strict increase.

3. Empty or single-element arrays

An empty array or a single element is trivially sorted. The loop simply doesn't execute, and you return true.

What You Learned

Key Takeaways

Pairwise comparison — examining relationships between adjacent elements.

Combined pattern — pairwise check + early termination.

This pattern is a building block for sorting verification and stability checks.
