Why First Non-Repeating Character?

Use Cases

Stream processing: Finding the first unique element in a data stream is a common interview variant.

Text analysis: Identifying unique characters for encoding, compression, or hashing.

Two-pass pattern: Many problems follow this "build a map, then scan" structure — first non-repeating teaches it cleanly.

What New Concept Does This Teach?

This exercise reinforces the frequency map + linear scan pattern: first pass builds the map in O(n), second pass scans the original data to find the first element satisfying a condition. The key insight is that the map gives O(1) lookups, so the second pass is also O(n), making the total O(n).

How It Works

The Algorithm

Pass 1 — Count: Iterate through the string, building a frequency map (character → count).

Pass 2 — Scan: Iterate through the string again. Return the first character whose count is 1.

If no character has count 1, return null or a sentinel value.

Time & Space Complexity

Time: O(n) — two passes over the string, each O(n). Map operations are O(1) average.

Space: O(k) — where k is the number of distinct characters (at most 26 for lowercase English).

Pseudocode

function first_non_repeating(s):
    freq = empty map

    // Pass 1: count frequencies
    for ch in s:
        freq[ch] = freq.get(ch, 0) + 1

    // Pass 2: find first with count == 1
    for ch in s:
        if freq[ch] == 1:
            return ch

    return null   // no non-repeating character

Walkthrough

Finding the first non-repeating character in "aabcbdef":

Pass 1: Build frequency map

a: 2, b: 2, c: 1, d: 1, e: 1, f: 1

Pass 2: Scan for count == 1

a → freq[a]=2, skip
a → freq[a]=2, skip
b → freq[b]=2, skip
c → freq[c]=1, FOUND! Return 'c'

Common Pitfalls

1. Scanning the map instead of the string

Hash maps do not preserve insertion order in most languages. You must scan the original string in the second pass to get the first non-repeating character.

2. Returning early during the counting phase

You cannot return a character the first time you see it with count 1 during counting — a duplicate might appear later. The two-pass approach is necessary.

What You Learned

Key Takeaways

Two-pass pattern: build a lookup structure, then scan the original data for answers.

O(n) time, O(k) space — optimal for this problem.

Map ordering matters: scan the original sequence, not the map, to preserve order.
