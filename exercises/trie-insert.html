Trie: Insert Word

Trie Beginner
Required Learning
  • #74 Trie: define TrieNode — the trie structure

The Problem

Definition

Insert a word into a trie (prefix tree). Walk character by character from the root, creating new nodes as needed. Mark the final node as an "end of word."

Real-World: Autocomplete Dictionary

When you type on your phone, the keyboard app stores its dictionary in a trie. Each word you insert becomes a path from the root. Sharing prefixes means "apple" and "app" share the first 3 nodes — saving memory and enabling instant prefix lookups.

How Insert Works

Character by Character

Starting at the root, for each character in the word:

  1. If the character exists as a child of the current node, move to that child.
  2. If not, create a new TrieNode and add it as a child, then move to it.

After processing all characters, mark the current node's is_end flag as true.

def insert(self, word):
    node = self.root
    for char in word:
        if char not in node.children:
            node.children[char] = TrieNode()
        node = node.children[char]
    node.is_end = True

Complexity

Time: O(m) where m = length of the word. One node visit per character.

Space: O(m) in the worst case (no shared prefix with existing words).

Walkthrough

Insert "cat", "car", "card" into an empty trie:

Insert "cat"

root → c (new) → a (new) → t (new, is_end=true)

Insert "car"

root → c (exists) → a (exists) → r (new, is_end=true)
The 'c' and 'a' nodes are shared with "cat"!

Insert "card"

root → c (exists) → a (exists) → r (exists) → d (new, is_end=true)
"car" and "card" share the path c→a→r. "car" is still marked as end.
Final trie:
root
 └─ c
    └─ a
       ├─ t ★        ("cat")
       └─ r ★        ("car")
          └─ d ★     ("card")

Common Pitfalls

1. Forgetting to mark is_end

Without is_end, you can't distinguish "car" (a word) from "car" (just a prefix of "card"). Always mark the end.

2. Case sensitivity

Tries are case-sensitive by default. "Cat" and "cat" would be different paths. Normalize to lowercase before inserting if you want case-insensitive behavior.
