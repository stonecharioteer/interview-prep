Trees: Serialize / Deserialize

Trees (Binary) Advanced
Prerequisites
  • #53 Preorder Traversal — visiting nodes in root-left-right order

What You Will Learn

Serialize a binary tree into a string so it can be stored or transmitted, then deserialize the string back into the exact same tree. Using preorder traversal with null markers ("#"), the tree structure is fully encoded. Watch the string grow as each node is visited, then watch nodes reappear as the string is consumed.

The Algorithm

Serialize (tree to string)

1. Preorder traversal: visit root, then left, then right.

2. For each node, append its value to the output string.

3. For each null child, append # (null marker).

4. Separate tokens with commas.

Deserialize (string to tree)

1. Split the string by commas into a list of tokens.

2. Consume tokens one by one, maintaining a pointer.

3. If the current token is #, return null (no node here).

4. Otherwise, create a node with the token's value, then recursively build its left and right subtrees.

Time & Space Complexity

Time: O(n) for both serialize and deserialize.

Space: O(n) for the output string / recursion stack.

Pseudocode

function serialize(root):
    result = []
    function preorder(node):
        if node is null:
            result.append("#")
            return
        result.append(str(node.val))
        preorder(node.left)
        preorder(node.right)
    preorder(root)
    return result.join(",")

function deserialize(data):
    tokens = data.split(",")
    index = 0
    function build():
        if tokens[index] == "#":
            index += 1
            return null
        node = new Node(int(tokens[index]))
        index += 1
        node.left = build()
        node.right = build()
        return node
    return build()

  Visit 4 -> "1,2,#,#,3,4"
  null    -> "1,2,#,#,3,4,#"
  null    -> "1,2,#,#,3,4,#,#"
  Visit 5 -> "1,2,#,#,3,4,#,#,5"
  null    -> "1,2,#,#,3,4,#,#,5,#"
  null    -> "1,2,#,#,3,4,#,#,5,#,#"

Result: "1,2,#,#,3,4,#,#,5,#,#"

Common Pitfalls

1. Forgetting null markers

Without null markers, you cannot distinguish between different tree shapes that have the same preorder values. The # markers encode the structure.

2. Pointer management in deserialize

The index/pointer must be shared across recursive calls (global or passed by reference). If each call maintains its own pointer, tokens get consumed out of order.

3. Choosing the wrong traversal

Preorder (root-left-right) works naturally because the root comes first, making deserialization straightforward. Other orderings work but require more complex logic.

What You Learned

Key Takeaways

Null markers encode structure: Without them, the same values could represent different trees. # tells the deserializer "stop, no child here."

Preorder is natural: Root first means you create the node, then recursively build children. The string is consumed left-to-right.

Serialize/Deserialize are inverses: One writes tokens, the other reads them in the same order. The symmetry is elegant.
