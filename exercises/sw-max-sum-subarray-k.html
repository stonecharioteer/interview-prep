EXERCISE #84

Sliding Window: Max Sum Subarray of Size k

Sliding Window Intermediate
Prerequisites
  • #83 sliding_window_sum — the fixed-size sliding window technique

What's New Here

In the previous exercise you computed all window sums. Now you only need the maximum. The sliding window technique is identical — you simply track a running max_sum alongside the window_sum.

This is a classic interview problem and a gentle introduction to optimization-over-windows.

The Algorithm

How It Works

1. Compute the sum of the first window of size k.
2. Set max_sum = window_sum.
3. Slide the window one position right: subtract the leaving element, add the entering element.
4. Update max_sum = max(max_sum, window_sum).
5. Repeat until the window reaches the end.

Time & Space Complexity

Time: O(n) — single pass after initial window computation.

Space: O(1) — only two variables: window_sum and max_sum.

Walkthrough

Find max sum subarray of size 3 in [2, 1, 5, 1, 3, 2]:

Step by step

Window [2, 1, 5]: sum = 8. max_sum = 8.
Slide: - 2 + 1 = 7. max_sum = max(8, 7) = 8.
Slide: - 1 + 3 = 9. max_sum = max(8, 9) = 9.
Slide: - 5 + 2 = 6. max_sum = max(9, 6) = 9.

Answer: 9 (subarray [5, 1, 3]).

Pseudocode

function max_sum_subarray_size_k(arr, k):
    n = len(arr)
    if n < k: return -1

    window_sum = sum(arr[0..k-1])
    max_sum = window_sum

    for i = k to n-1:
        window_sum += arr[i] - arr[i - k]
        max_sum = max(max_sum, window_sum)

    return max_sum

Common Pitfalls

1. Initializing max_sum to 0

If all elements are negative, max_sum = 0 would be wrong. Initialize it to the first window's sum.

2. Returning the sum instead of the subarray

Read the problem carefully. Some variants ask for the starting index or the subarray itself, not just the sum. Track the best starting index if needed.

What You Learned

Key Takeaways

Sliding window + running max is a common combination for optimization problems.

Once you can compute all window values in O(n), finding the best one is just an extra max() call per step.

This pattern extends to: max average subarray, smallest subarray with sum ≥ target, etc.
