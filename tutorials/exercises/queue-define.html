Queue: Define and Implement

Queues Beginner
Prerequisites
  • #1 Arrays — understanding indexed collections

What You Will Learn

This exercise introduces the queue — the FIFO counterpart to stacks. While stacks process the most recent item first, queues process the oldest item first. Queues model fairness: first come, first served.

What is a Queue?

Definition

A queue is an abstract data type that follows the First-In, First-Out (FIFO) principle. The first element added is the first one removed — like a line of people waiting at a counter.

Core Operations

enqueue(value): Add an element to the back (right end) of the queue.

dequeue(): Remove and return the element from the front (left end).

peek(): Look at the front element without removing it.

is_empty(): Check if the queue has no elements.

Why Use a Queue?

Real-World Use Cases

Print spooler: Print jobs are processed in the order they arrive.

Task scheduling: OS schedules processes in FIFO order (round-robin).

BFS traversal: Breadth-first search uses a queue to visit nodes level by level.

Customer service: Call centers, ticket systems, and checkout lines.

Message queues: Systems like RabbitMQ and Kafka process messages in order.

Time & Space Complexity

enqueue: O(1) — add to back.

dequeue: O(1) — remove from front (with linked list or circular buffer; O(n) with naive array).

peek: O(1) — read front element.

Space: O(n) — proportional to number of elements.

Pseudocode

structure Queue:
    data = []

    function enqueue(value):
        data.append(value)         // add to back

    function dequeue():
        if is_empty():
            error "queue is empty"
        return data.remove_first() // remove from front

    function peek():
        if is_empty():
            error "queue is empty"
        return data[0]             // look at front

    function is_empty():
        return length of data == 0

Stack vs Queue

Comparison

Stack (LIFO): Add and remove from the same end (top). Like a stack of plates.

Queue (FIFO): Add at one end (back), remove from the other (front). Like a line of people.

Choose a stack when you need "most recent first." Choose a queue when you need "oldest first."

Walkthrough

Step by step

enqueue(A): queue = [A]       front=A, back=A
enqueue(B): queue = [A, B]    front=A, back=B
enqueue(C): queue = [A, B, C] front=A, back=C
dequeue():  returns A, queue = [B, C]  front=B
dequeue():  returns B, queue = [C]     front=C
dequeue():  returns C, queue = []      empty!

Elements come out in the same order they went in: A, B, C. That is FIFO.

Common Pitfalls

1. Naive array dequeue is O(n)

Removing from the front of an array requires shifting all remaining elements. Use a linked list or circular buffer for true O(1) dequeue.

2. Dequeue on empty queue

Always check is_empty() before dequeuing.

What You Learned

Key Takeaways

FIFO principle: First in, first out. Fair and ordered processing.

Two ends: Unlike a stack (one end), a queue has a front and a back.

Foundation for BFS: Breadth-first search and level-order traversal depend on queues.
