Arrays: Remove Duplicates from Sorted Array

Arrays Intermediate
Prerequisites
  • #29 Arrays: basics

What You Will Learn

How to remove duplicates from a sorted array in-place using the slow/fast pointer technique. The slow pointer marks the boundary of unique elements; the fast pointer scans ahead. This runs in O(n) time with O(1) extra space.

The Problem

Definition

Given a sorted array nums, remove the duplicates in-place such that each element appears only once. Return the number of unique elements k. The first k elements of nums should hold the unique values.

Why Slow/Fast Pointers?

Key Insight

Because the array is sorted, duplicates are adjacent. The slow pointer tracks where the next unique element should go. The fast pointer scans forward. When nums[fast] != nums[slow], we found a new unique value — advance slow and copy.

Time & Space Complexity

Time: O(n) — single pass through the array.

Space: O(1) — modification is done in-place.

Speed

Pseudocode

function remove_duplicates_sorted(nums):
    if len(nums) == 0:
        return 0

    slow = 0

    for fast in range(1, len(nums)):
        if nums[fast] != nums[slow]:
            slow += 1
            nums[slow] = nums[fast]

    return slow + 1   // number of unique elements

Walkthrough

Tracing [1, 1, 2, 2, 3]

slow=0, fast=1: nums[1]=1 == nums[0]=1. Skip.
slow=0, fast=2: nums[2]=2 != nums[0]=1. slow=1, nums[1]=2. Array: [1,2,2,2,3]
slow=1, fast=3: nums[3]=2 == nums[1]=2. Skip.
slow=1, fast=4: nums[4]=3 != nums[1]=2. slow=2, nums[2]=3. Array: [1,2,3,2,3]
Done. Return slow+1 = 3. First 3 elements: [1,2,3].

Common Pitfalls

1. Assuming unsorted input

This technique only works on sorted arrays where duplicates are adjacent. For unsorted arrays, use a hash set.

2. Forgetting the +1

The slow pointer is an index (0-based). The count of unique elements is slow + 1.

What You Learned

Key Takeaways

Slow/fast pointer: A fundamental in-place array technique. Slow marks the write position, fast reads ahead.

Sorted invariant: When the array is sorted, duplicates are neighbors, enabling a single-pass solution.
