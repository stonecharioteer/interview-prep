What's New Here

Min/max/sum always scan the entire array. This exercise introduces early termination: you stop scanning the moment you find what you're looking for. This is a fundamental optimization — don't do more work than necessary. In the best case, you check just one element.

Why Check Membership?

Real-World Use Cases

Access control: Is this user ID in the allowed list?

Input validation: Is this value one of the accepted options?

Duplicate detection: Have we seen this item before? (check before inserting)

Feature flags: Is this feature name in the enabled list?

The Algorithm

How It Works

Walk through the array comparing each element to the target. If you find a match, return true immediately — no need to check the rest. If you exhaust the entire array without finding a match, return false.

Time & Space Complexity

Time: O(n) worst case (element not present or at the end).

Best case: O(1) — the target is the very first element.

Space: O(1) — no extra storage needed.

Step by step

Index 0: 5 == 8? No, continue.
Index 1: 12 == 8? No, continue.
Index 2: 8 == 8? Yes! Return true immediately.
(Indices 3, 4, 5 are never checked.)

Pseudocode

function contains(arr, target):
    for i from 0 to len(arr) - 1:
        if arr[i] == target:
            return true       // early termination!
    return false               // exhausted all elements

Common Pitfalls

1. Returning too early (false)

Don't return false inside the loop when an element doesn't match. You can only conclude "not found" after checking every element.

2. Not using early termination

A common beginner mistake is scanning the entire array even after finding the target. Once found, stop immediately.

3. Equality semantics

Be careful with how your language compares values. Floating-point numbers, strings with different casing, and object references can all cause surprises.

What You Learned

Key Takeaways

Early termination can dramatically improve best-case performance.

Linear search is O(n) in the worst case — for sorted data, binary search does better.

The "return immediately on match" pattern appears in many algorithms.
