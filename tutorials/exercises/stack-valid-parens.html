Stack: Valid Parentheses

Stacks Beginner
Prerequisites
  • #14 Stack: Define — understanding push, pop, peek, is_empty

What You Will Learn

This is the classic first application of a stack. You will learn how to use a stack to match pairs — every opening bracket must have a corresponding closing bracket in the correct order. This pattern extends to HTML tags, function calls, and any nested structure.

The Problem

Definition

Given a string containing only the characters (, ), {, }, [, ], determine if the string is valid. A string is valid if:

1. Every opening bracket has a matching closing bracket of the same type.

2. Brackets are closed in the correct (nested) order.

Why Use a Stack?

Real-World Use Cases

Code editors: Highlighting mismatched brackets as you type.

HTML validation: Ensuring every <div> has a </div>.

Math expressions: Verifying ((2+3)*4) has balanced parentheses.

Compilers: Syntax analysis of nested constructs.

Key Insight

When you encounter a closing bracket, the most recent unmatched opening bracket must be its match. "Most recent" means last in — exactly what a stack gives you.

Time & Space Complexity

Time: O(n) — process each character exactly once.

Space: O(n) — in the worst case, all characters are opening brackets.

Pseudocode

function is_valid(s):
    stack = new Stack()
    matching = { ')': '(', '}': '{', ']': '[' }

    for each char in s:
        if char is '(' or '{' or '[':
            stack.push(char)
        else:
            if stack.is_empty():
                return false    // nothing to match
            if stack.pop() != matching[char]:
                return false    // wrong bracket type
    return stack.is_empty()     // all brackets matched?

Walkthrough

Tracing "(()[{}])"

char '(':  opening, push.   Stack: ['(']
char '(':  opening, push.   Stack: ['(', '(']
char ')':  closing, pop '('. Matches! Stack: ['(']
char '[':  opening, push.   Stack: ['(', '[']
char '{':  opening, push.   Stack: ['(', '[', '{']
char '}':  closing, pop '{'. Matches! Stack: ['(', '[']
char ']':  closing, pop '['. Matches! Stack: ['(']
char ')':  closing, pop '('. Matches! Stack: []
End: stack is empty. VALID.

Tracing "([)]" — invalid

char '(':  push.   Stack: ['(']
char '[':  push.   Stack: ['(', '[']
char ')':  pop '['. Expected '(' but got '['. MISMATCH! INVALID.

Common Pitfalls

1. Forgetting the final empty check

The string "(((" processes without errors, but the stack is not empty at the end. That means unmatched opening brackets remain.

2. Popping from an empty stack

The string ")" has a closing bracket with nothing to match. Always check is_empty() before popping.

What You Learned

Key Takeaways

Pair matching: Stacks naturally match nested pairs because the most recent opener is always on top.

Pattern recognition: Whenever you see "match the most recent unmatched item," think stack.
