Bits: Is Power of Two

Bits Beginner

Starting Point

This is your introduction to bit manipulation. No prerequisites needed beyond basic integers. You will learn what binary representation is and discover your first bit trick.

What Are Bits?

Binary Representation

Every integer is stored in memory as a sequence of bits — binary digits that are either 0 or 1. The number 13 in decimal is 1101 in binary:

1×8 + 1×4 + 0×2 + 1×1 = 13

Each bit position represents a power of 2. The rightmost bit is 2&sup0; = 1, the next is 2¹ = 2, then 2² = 4, and so on.

Why Check for Power of Two?

Use Cases

Memory allocation: Page sizes, buffer sizes, and hash table capacities are often powers of 2 for alignment and fast modulo (using AND instead of %).

Hash tables: Hash table sizes are typically powers of 2 so that hash % size can be computed as hash & (size - 1), which is much faster.

Graphics: Texture dimensions are powers of 2 for GPU efficiency.

Interview favorite: This problem teaches the n & (n - 1) trick, one of the most elegant bit manipulation patterns.

What New Concept Does This Teach?

This teaches you to think in binary. A power of 2 has exactly one bit set: 1=1, 2=10, 4=100, 8=1000. The trick n & (n - 1) clears the lowest set bit. If the result is 0, there was only one set bit — meaning n is a power of 2.

The Algorithm

The n & (n - 1) Trick

When you subtract 1 from a binary number, all bits below the lowest set bit flip:

  n   = 01000000    (64, a power of 2)
  n-1 = 00111111    (63)
  n & (n-1) = 00000000    → 0, so it IS a power of 2

  n   = 01100000    (96, NOT a power of 2)
  n-1 = 01011111    (95)
  n & (n-1) = 01000000    → not 0, so NOT a power of 2

Time & Space Complexity

Time: O(1) — a single subtraction and a single AND operation.

Space: O(1)

Pseudocode

function is_power_of_two(n):
    if n <= 0:
        return false
    return (n AND (n - 1)) == 0

Powers of Two Reference

Common Powers of 2

2^0  = 1       2^5  = 32      2^10 = 1024 (1K)
2^1  = 2       2^6  = 64      2^16 = 65536 (64K)
2^2  = 4       2^7  = 128     2^20 = 1048576 (1M)
2^3  = 8       2^8  = 256     2^30 = ~1 billion (1G)
2^4  = 16      2^9  = 512     2^32 = ~4 billion

Common Pitfalls

1. Zero and negative numbers

0 & (0 - 1) equals 0, but 0 is NOT a power of 2. Always check n > 0 first.

2. Signed integers

Negative numbers have the sign bit set and are never powers of 2. The n > 0 check handles this.

What You Learned

Key Takeaways

Binary representation is the foundation for all bit manipulation.

n & (n - 1) clears the lowest set bit — a trick you will reuse in counting set bits and more.

Single-operation checks are faster than loops and division.
