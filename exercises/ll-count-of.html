New Concept: Conditional Counting

Length counts every node. Count-of counts only nodes that match a condition. This combines the traversal pattern with a filter — you increment the counter only when the node's value equals the target.

This is the "count with predicate" pattern: traverse, test a condition, accumulate matches. It generalizes to counting even numbers, values above a threshold, etc.

Time & Space Complexity

Time: O(n) — must check every node (target could appear anywhere, including multiple times).

Space: O(1) — one counter variable.

Pseudocode

function count_of(head, target):
    count = 0
    curr = head
    while curr is not null:
        if curr.value == target:
            count = count + 1
        curr = curr.next
    return count

What You Learned

Key Takeaways

Conditional counting = traversal + predicate + accumulator.

Unlike find, you do NOT exit early — you must scan the entire list to count all occurrences.

This pattern generalizes: change the condition to count evens, negatives, values in a range, etc.
