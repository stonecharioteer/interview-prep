Why Minimum Window Substring?

The Problem

Given strings s and t, find the smallest substring of s that contains all characters of t (including duplicates).

Example: s = "ADOBECODEBANC", t = "ABC" → answer is "BANC".

What New Concept Does This Teach?

This combines the expand/shrink sliding window pattern with character frequency tracking. You expand the right pointer to include more characters until all of t is covered, then shrink from the left to find the minimum valid window. This two-pointer dance runs in O(n).

The Approach

Expand and Shrink

1. Build a frequency map of characters in t (what we need).

2. Expand the window by moving the right pointer. Track how many required characters are satisfied.

3. Once all characters are satisfied, shrink from the left to minimize the window. Record the best window found.

4. Continue expanding right and shrinking left until the right pointer reaches the end.

Key Tracking Variables

need: frequency map of characters in t.

have: frequency map of characters in the current window.

formed: number of unique characters in t that are fully satisfied in the window.

When formed == required (number of unique chars in t), the window is valid.

Time & Space Complexity

Time: O(n) — each character is visited at most twice (once by right, once by left).

Space: O(k) where k is the number of unique characters in s and t.

Pseudocode

function min_window_substring(s, t):
    need = frequency_map(t)
    have = {}
    required = len(need)   // unique chars needed
    formed = 0
    best = ""
    left = 0

    for right in 0..len(s)-1:
        char = s[right]
        have[char] = have.get(char, 0) + 1

        if char in need and have[char] == need[char]:
            formed += 1

        while formed == required:
            // update best window
            window = s[left..right+1]
            if best == "" or len(window) < len(best):
                best = window

            // shrink from left
            left_char = s[left]
            have[left_char] -= 1
            if left_char in need and have[left_char] < need[left_char]:
                formed -= 1
            left += 1

    return best

Common Pitfalls

1. Not handling duplicate characters in t

If t = "AAB", you need at least 2 A's and 1 B in the window. Track frequencies, not just presence.

2. Forgetting to shrink

After finding a valid window, you must keep shrinking from the left to find the minimum. The inner while loop is essential.

3. Off-by-one in substring

The window is s[left..right+1] (inclusive of both left and right). Double-check your slicing.

What You Learned

Key Takeaways

The expand/shrink pattern: grow right to satisfy constraints, shrink left to minimize.

Track formed vs required to know when the window is valid.

Each pointer moves at most n times, giving O(n) total time.
