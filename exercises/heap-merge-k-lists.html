Heap: Merge K Sorted Lists

Heap Advanced
Prerequisites
  • #134 Merge Two Heaps — merging heaps using heapify
  • #78 LL: Merge Two Sorted Lists — merging two sorted linked lists

What You Will Learn

Given k sorted linked lists, merge them into one sorted list. A min-heap of size k always holds the current front of each list. Each step: extract the minimum from the heap, add it to the output, and push the next element from that list into the heap.

Mental model: k runners on k tracks. The heap is a leaderboard that always tells you which runner is currently in the lead (has the smallest value). You record the leader, then that runner advances to their next checkpoint.

The Algorithm

How It Works

1. Push the head of each list into a min-heap (heap contains pairs: (value, list-index)).

2. While the heap is not empty:

   a. Extract the minimum (value, list-index).

   b. Append value to the output list.

   c. If that list has a next element, push it into the heap.

3. Return the output list.

Time & Space Complexity

Time: O(N log k) — N = total elements across all lists. Each heap op is O(log k).

Space: O(k) — the heap always holds at most k elements (one per list).

Pseudocode

function mergeKLists(lists):
    heap = new MinHeap()  // stores (value, listIndex)
    for i in range(len(lists)):
        if lists[i] is not empty:
            heap.push( (lists[i][0], i) )
            advance pointer for list i

    output = []
    while heap is not empty:
        (val, listIdx) = heap.extractMin()
        output.append(val)
        if list[listIdx] has more elements:
            heap.push( (nextVal, listIdx) )
            advance pointer for list[listIdx]

    return output

Common Pitfalls

1. Forgetting to push the next element from the same list

After extracting from the heap, you must push the next element from that specific list. Forgetting this means you lose elements.

2. Not handling empty lists

Some of the k lists might be empty. Skip them during initialization. Also, after extracting, check if the list has more elements before pushing.

3. Merging all then sorting: O(N log N) vs O(N log k)

Concatenating all elements and sorting is O(N log N). The heap approach is O(N log k). When k is much smaller than N, the heap approach is significantly faster.

What You Learned

Key Takeaways

Heap as a multi-way merge tool: A min-heap efficiently picks the smallest among k candidates.

O(N log k) is optimal: Each of the N elements enters and leaves the heap exactly once.

The k-runners model: The heap is a leaderboard tracking which runner is currently in the lead.
