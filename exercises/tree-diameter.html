Trees: Diameter (Longest Path)

Trees (Binary) Intermediate
Prerequisites
  • #89 Tree Height — computing height of a binary tree

What You Will Learn

The diameter of a binary tree is the length of the longest path between any two nodes (measured in edges). This path may or may not pass through the root. At each node, the potential diameter passing through it = leftHeight + rightHeight. Imagine stretching a rubber band through the tree — the diameter is the longest it can stretch.

The Algorithm

How It Works

1. Recursively compute the height of each subtree bottom-up.

2. At each node, the diameter through this node = leftHeight + rightHeight.

3. Track the global maximum diameter seen so far.

4. Return height (= max(leftH, rightH) + 1) to the parent for its calculation.

The key insight: the longest path through any node is the sum of its left and right subtree heights.

Time & Space Complexity

Time: O(n) — visit each node once (bottom-up).

Space: O(h) — recursion stack depth.

Speed

Pseudocode

function diameter(root):
    bestDiameter = 0

    function height(node):
        if node is null: return 0
        leftH = height(node.left)
        rightH = height(node.right)
        bestDiameter = max(bestDiameter, leftH + rightH)
        return max(leftH, rightH) + 1

    height(root)
    return bestDiameter

Walkthrough

       / \

    4  5 6  7

Bottom-up heights:
  4: h=1, 5: h=1, 6: h=1, 7: h=1
  2: lH=1, rH=1 -> path=2, h=2
  3: lH=1, rH=1 -> path=2, h=2
  1: lH=2, rH=2 -> path=4, h=3

Best diameter = 4 (path: 4->2->1->3->7)

Common Pitfalls

1. Assuming diameter passes through root

The longest path might be entirely within one subtree! That is why you track a global max at every node, not just the root.

2. Returning diameter instead of height

The recursive function returns height to its parent. The diameter is tracked as a side-effect (global variable). Confusing these leads to wrong answers.

3. Edges vs. nodes

Diameter is measured in edges (= leftH + rightH). Some definitions use node count (= leftH + rightH + 1). Know which your problem expects.

What You Learned

Key Takeaways

Diameter = leftH + rightH: At each node, the longest path through it equals the sum of subtree heights.

Global max, local return: Track diameter globally but return height locally. This is a common pattern in tree problems.

Not always through root: The diameter can be deep inside a subtree. The rubber-band mental model helps: stretch it everywhere, measure the longest.
