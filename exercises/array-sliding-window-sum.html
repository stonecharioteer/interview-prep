What's New Here

Previously you computed a single sum over the entire array. Now you need the sum of every contiguous subarray of size k. The naive approach recomputes each window from scratch: O(nk). The sliding window technique reuses the previous sum by subtracting the element leaving the window and adding the element entering it — O(n).

This is your first encounter with the fixed-size sliding window pattern, one of the most important techniques in array/string problems.

Naive vs Sliding Window

The Key Insight

Consecutive windows overlap in k−1 elements. Recomputing the sum from scratch wastes work. Instead, slide the window one position right:

new_sum = old_sum - arr[i-1] + arr[i+k-1]

ApproachTimeSpace
Naive (recompute each window)O(nk)O(1)
Sliding windowO(n)O(1)

Time & Space Complexity

Time: O(n) — one pass through the array after computing the initial window.

Space: O(n−k+1) for the output array, O(1) extra working space.

Step by step

Initial window [1, 3, 2]: sum = 6
Slide: subtract arr[0]=1, add arr[3]=6: sum = 6 - 1 + 6 = 11
Slide: subtract arr[1]=3, add arr[4]=4: sum = 11 - 3 + 4 = 12
Slide: subtract arr[2]=2, add arr[5]=1: sum = 12 - 2 + 1 = 11
Slide: subtract arr[3]=6, add arr[6]=8: sum = 11 - 6 + 8 = 13
Slide: subtract arr[4]=4, add arr[7]=5: sum = 13 - 4 + 5 = 14

Result: [6, 11, 12, 11, 13, 14]

Pseudocode

function sliding_window_sum(arr, k):
    n = len(arr)
    if n < k: return []

    // compute first window
    window_sum = 0
    for i = 0 to k-1:
        window_sum += arr[i]

    result = [window_sum]

    // slide the window
    for i = k to n-1:
        window_sum += arr[i]       // add entering element
        window_sum -= arr[i - k]   // subtract leaving element
        result.append(window_sum)

    return result

Common Pitfalls

1. Off-by-one when computing the first window

The first window spans indices [0, k-1]. Make sure you sum exactly k elements before sliding.

2. Forgetting to handle n < k

If the array has fewer than k elements, no valid window exists. Return an empty result.

3. Wrong subtract/add order

When sliding from position i to i+1, subtract arr[i] (left edge leaving) and add arr[i+k] (right edge entering). Mixing these up gives wrong sums.

What You Learned

Key Takeaways

The sliding window technique avoids redundant work by reusing the previous computation.

Fixed-size windows are the simplest variant: window always has exactly k elements.

This pattern generalizes to many problems: max/min in window, averages, and more.
