Trie: starts_with (Prefix Search)

Trie Beginner
Prerequisites
  • #82 Trie: Insert & #92 Trie: Search — basic trie structure and traversal

Why starts_with?

Use Cases

Autocomplete: As a user types, check if any word in the dictionary starts with the typed prefix.

IP routing: Longest-prefix matching in routers is essentially a trie starts_with query.

Spell check: Quickly determine if a prefix could lead to valid words.

What New Concept Does This Teach?

The key insight: starts_with is almost identical to search, but you do not check isEndOfWord at the end. You only need to verify that every character in the prefix has a corresponding child node in the trie. If you reach the end of the prefix without falling off the trie, the prefix exists.

The Approach

Walk the Prefix

Start at the root. For each character in the prefix, check if the current node has a child for that character. If yes, move to that child. If no, return false.

If you successfully walk through all characters, return true — regardless of whether the final node is marked as an end-of-word.

Difference from search()

search("app") returns true only if "app" was inserted as a complete word.

starts_with("app") returns true if any word starting with "app" exists (e.g., "apple", "application").

Time & Space Complexity

Time: O(m) where m is the length of the prefix.

Space: O(1) — no extra space beyond the pointer walking the trie.

Speed

Pseudocode

function starts_with(prefix):
    node = root
    for char in prefix:
        if char not in node.children:
            return false
        node = node.children[char]
    return true          // do NOT check node.isEndOfWord

Common Pitfalls

1. Checking isEndOfWord

The most common mistake: adding return node.isEndOfWord at the end. That turns starts_with into search. For prefix checking, just return true after walking all characters.

2. Empty prefix

An empty prefix should return true — every word starts with the empty string. The loop body never executes, and you return true immediately.

What You Learned

Key Takeaways

starts_with = walk the prefix in the trie, skip the isEndOfWord check.

Time is O(m) where m = prefix length — independent of how many words are in the trie.

This is the foundation for autocomplete and prefix-based filtering.
