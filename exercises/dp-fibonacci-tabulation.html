EXERCISE #99

DP: Fibonacci Tabulation (Bottom-Up)

Dynamic Programming Beginner
Prerequisites
  • #98 Fibonacci with Memoization — top-down DP that you will now flip upside-down

What You Will Learn

This is your introduction to Dynamic Programming (DP). You already know memoization (top-down DP). Now you will learn tabulation (bottom-up DP): instead of recursing and caching, you fill a table from the smallest subproblems up. No recursion. No call stack. Just a simple loop that fills an array, one cell at a time.

What is Dynamic Programming?

Definition

Dynamic Programming is an optimization technique for problems with two properties:

1. Optimal substructure: The solution to a problem can be built from solutions to its subproblems.

2. Overlapping subproblems: The same subproblems are solved multiple times.

DP solves each subproblem once and stores the result. Two approaches:

Top-down (memoization): Recurse + cache. You did this in #98.

Bottom-up (tabulation): Fill a table iteratively, starting from the base cases. That is this exercise.

Time & Space Complexity

Time: O(n) — one pass through the table, filling each cell in O(1).

Space: O(n) — the dp array. (Can be optimized to O(1) by keeping only the last two values, but the table is clearer for learning.)

Speed

Pseudocode

function fib_tabulation(n):
    if n <= 0: return 0
    dp = array of size n+1
    dp[0] = 0               // base case
    dp[1] = 1               // base case
    for i from 2 to n:
        dp[i] = dp[i-1] + dp[i-2]   // build from smaller
    return dp[n]

Walkthrough

Filling the table for fib(7)

dp = [_, _, _, _, _, _, _, _]

Base cases:
  dp[0] = 0
  dp[1] = 1

Fill loop:
  dp[2] = dp[1] + dp[0] = 1 + 0 = 1
  dp[3] = dp[2] + dp[1] = 1 + 1 = 2
  dp[4] = dp[3] + dp[2] = 2 + 1 = 3
  dp[5] = dp[4] + dp[3] = 3 + 2 = 5
  dp[6] = dp[5] + dp[4] = 5 + 3 = 8
  dp[7] = dp[6] + dp[5] = 8 + 5 = 13

Return dp[7] = 13

Common Pitfalls

1. Off-by-one on table size

You need n+1 cells (indices 0 through n). Creating an array of size n misses the last cell.

2. Forgetting to handle n=0 or n=1

If n is 0, the loop does not run and you return dp[0] = 0. If n is 1, same. Make sure your base cases cover these.

3. Thinking DP is always hard

Fibonacci tabulation is just a for loop filling an array. The pattern — identify subproblems, write a recurrence, fill a table — applies to all DP problems. Start simple.

What You Learned

Key Takeaways

Bottom-up DP = fill a table iteratively. Start from base cases, build up to the answer. No recursion needed.

Same O(n) as memoization but without recursion overhead or stack depth concerns.

The DP pattern: 1. Define subproblems. 2. Write the recurrence (dp[i] = ...). 3. Identify base cases. 4. Fill the table in order.
